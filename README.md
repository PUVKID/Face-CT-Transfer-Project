# 🫁 Face CT Transfer Project

얼굴 사전학습 모델을 폐 CT 진단 분류에 전이하고, 영상 필터가 분류 성능에 미치는 영향을 비교합니다. 코드·설정·실측 결과·실패 및 한계를 함께 보존합니다.

**기술 분류:** 컴퓨터 비전 · 전이학습 · 의료 영상 분류 · 영상 변형 평가

[전체 차수와 회차](docs/REVISION_INDEX.md) · [1단계 총괄 보고서](1단계/1차/reports/총괄_보고서.md) · [모델 선정 근거](1단계/1차/docs/모델_선정_근거.md) · [재현](1단계/1차/docs/재현_안내.md) · [변경 기록](CHANGELOG.md)

## 🔬 관측 결과

1단계의 주후보는 AdaFace IR101 WebFace12M입니다. 공식 가중치의 SHA-256 및 917개 텐서의 엄격 적재를 확인했습니다. 실제 합성 입력 진단 30항목 중 29개 통과·channels_last 1개 미지원·실패 0개입니다. 독립 검증자가 CPU·GPU 기준 실행과 단위 검사 17개를 확인했습니다.

**이것은 30회 학습이나 CT 진단 정확도 결과가 아닙니다.** 얼굴 인식 최고 성능이 CT 최고 성능을 보장하지 않습니다. 실제 CT 학습과 필터 성능 비교는 다음 단계로 구분합니다. 현재 공개한 개별 검토 보고서는 30/30개입니다.

## 📊 공통 평가 설계

환자별 분할이 검증되는 자료에서 7-fold와 내부 검증을 사용하고, 같은 데이터 분할·전처리·학습 예산·모델 선택 기준을 공유합니다. 불균형 보정, 조기 종료, 스케줄러, 혼합정밀도, 클래스별 지표, 보정도, 신뢰구간, 외부 검증을 구분해 평가합니다. 기법의 효과는 별도 비교하며 무조건 섞지 않습니다. [프로토콜](1단계/1차/docs/공통_실험_프로토콜.md)

## 📦 데이터와 이용 조건

원 CT·개별 환자 정보·특징 벡터·가중치·비공개 운영 기록은 이 저장소에 올리지 않습니다. LUNA25 영상과 주석의 라이선스는 별개이며, 정상 클래스가 없는 양성·악성 결절 자료입니다. 데이터 중복과 라벨 정의를 확인하지 않은 단순 병합은 하지 않습니다. [LUNA25 영상](https://zenodo.org/records/14223624) · [주석](https://zenodo.org/records/14673658)

공식 얼굴 가중치와 학습 데이터의 이용 조건을 준수해야 합니다. 코드의 MIT 표기가 가중치 전체의 상업권을 뜻하지 않습니다. [공식 모델 카드](https://huggingface.co/minchul/cvlface_adaface_ir101_webface12m)

코드와 문서 작성·검사는 AI 지원을 사용했습니다. 이 단계의 보고서는 연구 준비 기술 보고서이며 완성 논문·임상 검증·익명성 보장을 주장하지 않습니다.
