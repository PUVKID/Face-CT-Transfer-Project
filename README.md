얼굴 사전학습 모델을 폐 CT 진단 분류에 전이하고, 영상 필터가 분류 성능에 미치는 영향을 비교합니다. 코드·설정·실측·실패와 한계를 함께 보존합니다.

**기술 분류:** 컴퓨터 비전 · 전이학습 · 의료 영상 분류 · 영상 변형 평가

## 🔬 확인한 내용

1단계는 AdaFace IR101 WebFace12M의 공식 SHA-256, 917개 텐서의 엄격 적재, 합성 입력 진단 30항목을 확인했습니다. 결과는 29통과·channels_last 1미지원·실패0이며 CPU·GPU 기준 실행과 단위 검사 17개를 별도로 확인했습니다. **30회 학습이나 CT 진단 정확도 결과가 아닙니다.** 기존 개별 검토 보고서는 30개입니다.

2단계는 실제 자료 준비·재개 가능한 학습 코드·수리 후 36개 단위 검사와 새 자원 측정을 완료했습니다. LUNA25 주석 시점 6,163개·고유 결절 3,762개·환자 2,120명과 IQ 영상 1,097개·정확 중복 그룹 1,054개를 구분했습니다. 공통 IQ 배치 16을 선택하고 BF16 학습·FP32 특징 및 평가·최초 실행부터 7일 상한을 고정했습니다. **실제 학습은 2026-11-03 06:46에 시작했으나 06:48 마지막 한 영상 배치의 배열 차원 오류로 중단됐습니다. 수리 후 36개 검사를 통과했고 07:01 새 측정에서 배치 16을 선택했습니다. 독립 재검증의 36개 검사를 통과한 뒤 07:12:34 한국 시각에 실제 학습을 재시작했습니다. 07:12 확인 시점에는 특징 계산 중이며 LUNA25 완료 외부 fold 0개·IQ 완료 설정 0/30이었습니다. 이번 공개 초안에는 임상 지표·완료된 30설정 보고서가 없습니다.** IQ는 환자 매핑이 확인되지 않은 탐색 분석입니다.

## 📊 분석과 실행

LUNA25는 환자 그룹 7-fold와 내부 검증으로 원래 얼굴 고정 특징의 이진 분석을 수행합니다. 전체 LUNA25 보조 적응은 IQ용 초기화에만 사용하고 LUNA25 시험 평가에 섞지 않습니다. IQ는 두 초기화×세 학습 범위×다섯 시드의 30설정을 같은 정확 중복 그룹 분할로 비교하는 계획입니다. 6개 방법의 5회 반복이며 30개 독립 방법이나 30개 완료 결과가 아닙니다. 외부 시험 fold는 조기 종료·모델 선택·온도 보정에 쓰지 않습니다.

## 📦 공개 범위와 이용 조건

코드·검사·설정·집계 기술 기록만 공개합니다. 원 CT·환자/영상 키·특징·가중치·개별 예측·비공개 운영 기록은 제외합니다. [LUNA25 영상](https://zenodo.org/records/14223624)은 CC BY 4.0, [주석](https://zenodo.org/records/14673658)은 CC BY-NC 4.0이며 정상 클래스가 없습니다. IQ 정상 영상과 LUNA25 결절 ROI를 한 클래스 표로 합치지 않습니다.

[공식 얼굴 모델 카드](https://huggingface.co/minchul/cvlface_adaface_ir101_webface12m)의 코드·가중치·학습 자료 조건을 별도로 준수합니다. 모델 코드의 MIT 표기를 가중치 전체의 상업적 이용 허용으로 해석하지 않습니다.

코드와 문서 작성·검사에 AI 지원을 사용했습니다. 현재 문서는 기술 기록이며 논문 원고·동일 원고 PDF는 없습니다. 얼굴 최고 성능·CT 임상 일반화·익명성 보장을 주장하지 않습니다.

IQ 보유 JPG 1,097개는 [저자 GitHub 고정 커밋](https://github.com/hamdalla93/The-IQ-OTHNCCD-lung-cancer-dataset/tree/edcdd5a73e8e92377d2a47e69c0b9a551e1c5ce3)의 1,097개와 상대 경로·길이·Git blob SHA-1이 모두 일치했습니다. Mendeley ZIP 전체와 환자 매핑은 미검증이며 설명의 1,190영상·110명을 보유자료의 확정 수치로 사용하지 않습니다.

## 2026-11-03 07:12 재시작 확인

수리 뒤 독립 검증에서 36개 검사를 모두 통과했고, 마지막 한 영상 배치·읽기 전용 memmap·중단 후 재개 경로를 추가 확인했습니다. 이전 33개 검사 통과와 06:48 첫 실제 실행 실패는 그대로 보존합니다. 07:01 새 자원 측정에서 공통 배치 16을 선택한 소스로 07:12:34 한국 시각에 실제 학습을 재시작했습니다.

07:12 확인 시점에는 특징 계산 중이었고 LUNA25 이진 평가의 완료 외부 fold는 0개, IQ 완료 설정은 0/30이었습니다. 이는 재시작 상태 관측이며 임상 분류 결과가 아닙니다. 이번 묶음은 코드·자료 준비·자원 실측의 공개이며 30설정 결과 보고서나 결과 공개 커밋 횟수에 포함하지 않습니다. 이후 실제 학습 결과는 별도 검증해 공개합니다.
