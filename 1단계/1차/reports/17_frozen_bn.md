# 1단계 1차 검토 17: 동결 훈련에서 백본 배치 정규화 통계가 보존된다

작성일: 2026-11-03 · 구분: 사전학습 모델의 엔지니어링 검토 · 결과: **통과**

## 연구 질문과 필요성

requires_grad=False만으로는 BatchNorm의 running statistics가 동결되지 않는다. 학습 중 동결 백본의 평가 모드가 유지되는지 확인한다.

## 고정된 조건

모델은 AdaFace IR101 WebFace12M, 가중치 revision `54f602a0737bd1ee4a4e7e9fd089a485f397fefd`이다. 가중치 SHA-256은 `e312d79222d28027f146ed495e182e48fe0dddf404cdbbdabcccdbdd07cc3758`이며 원본 917개 텐서를 안전한 state_dict로 엄격 적재했다. 입력 규격은 RGB 3×112×112, 정규화는 `(x-0.5)/0.5`, 분류기는 512차원 특징에서 세 로짓을 계산한다. 시드 20261103, PyTorch 2.11.0+cu128, CUDA 12.8, RTX 4090을 사용했다.

대상은 합성 비인체 입력과 입력 오류 경로다. 얼굴 인물 식별·환자 재식별·CT 진단 정확도·7-fold 학습은 이 검토에서 수행하지 않았다. 실행 장치: CUDA 기준 실행; 입력 전처리 등 일부 검사는 CPU 텐서 사용.

## 방법과 직접 관측

검사 식별자는 `frozen_bn`이다. 실제 구현과 판정 조건은 [진단 코드](../src/diagnostics.py), [고정 30항목](../configs/stage1_cases.json)에 있다. 본문 수치는 개별 실행 JSON에서 가져왔다. 단위 검사의 모의 백본 결과와 실제 사전학습 백본 실행 결과를 구분한다.

측정 시작(UTC): `2026-11-02T19:34:31.312184+00:00`. 검사 시간은 **0.096168초**다. 이 시간에는 검사별 상태 보존·복원 비용이 포함되므로 일반 추론 처리량이나 학습 시간으로 해석하지 않는다. PyTorch가 기록한 검사 구간 최대 CUDA 할당은 **360,206,336바이트**이며, 다른 프로세스·드라이버·예약 메모리를 포함한 전체 GPU 사용량이 아니다.

## 판정과 한계

판정은 **통과**다. 미지원은 통과로 합산하지 않는다. 합성 경사·업데이트 검사는 전이학습 연결이 가능한지 보는 것이며 실제 CT에 대한 학습 효과를 증명하지 않는다. 30개 검토를 30회의 독립 학습 또는 30개 임상 실험으로 보고하지 않는다.

원본 실행 1회차에서 CPU·CUDA 일치 검사에 추론 모드와 장치 이동의 상태 복원 오류가 있었고, 원문을 보존한 뒤 수정했다. 최종 2회차는 같은 허용 오차에서 29개 통과·channels_last 1개 미지원·실패 0개였다. 독립 검증자는 CPU·CUDA 기준으로 별도 실행하여 같은 상태 집계를 확인했다. 최초 실패는 나중 성공으로 지우지 않았다.
