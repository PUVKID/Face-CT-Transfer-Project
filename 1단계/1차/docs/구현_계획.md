# 1단계 얼굴 모델 선정·전이 준비 계획

목표: 강력한 공개 얼굴 사전학습 모델을 원출처 근거로 선정하고 CT 진단 분류에 사용할 수 있는지 30개 서로 다른 항목으로 검토한다.

구조: source는 E:/2026/Face CT Transfer Project/1단계/1차 폴더다. 데이터·모델·가상환경·비공개 운영 기록은 같은 1단계 안의 data·models·work에 분리하고, 공개 사본은 work 안의 별도 일반 Git 폴더를 사용한다. 이전 프로젝트 자료는 수정하지 않는다.

## 작업

- [ ] 공식 논문과 저자 저장소에서 모델 후보·비교 가능한 벤치마크·라이선스·학습 가능한 가중치를 조사한다.
- [ ] 모델 다운로드 검증·입력 전처리·특징 추출·3출력 분류기 결합을 구현한다. 실패 경로와 가중치 누락·형상 오류·비유한 값·무작위 초기화 오표기를 검사한다.
- [ ] 실제 사전학습 가중치를 내려받아 해시를 보존하고, CPU에서 합성 비인체 입력으로 추론·경사·업데이트·동결 동작을 직접 검사한다. 원본 모델을 수정 없이 별도 보관한다.
- [ ] 30개 검토 각각의 연구 질문·방법·증거·결과·한계를 보고서와 기계 판독 결과에 기록한다. 합성 검사에서 정확도나 임상 성능을 만들지 않는다.
- [ ] 별도 verifier가 소스·결과·조건·공개 안전성을 직접 검사한다. 수정이 생기면 다시 동결하여 검증한다.
- [ ] 각 회차의 공개 변경을 별도 커밋·푸시하고 30회 원격 커밋 및 파일을 확인한다. 전체 차수표·회차표·직전 비교·공개용 변경 기록을 연결한다.
- [ ] 필수 공개 검사와 영수증을 확인한 뒤 2단계 데이터 확보·진단 분류로 진행한다.

## 핵심 검증

고정된 체크포인트에서 누락 없이 state_dict가 적재되는지, 입력 색상·크기·정규화가 공식 구현과 일치하는지, 분류기 출력이 세 개이며 환자 ID가 아닌지, 합성 입력의 경사가 실제 파라미터에 도달하는지, 테스트가 실제 CT 성능으로 오표기되지 않았는지 확인한다.
