# 1단계 재현 안내

이 단계는 CT 학습이 아닌 합성 비인체 입력의 전이 준비 검사다. 원본 모델 구조와 가중치를 공개 출처에서 별도로 받아야 하며 저장소에는 재배포하지 않는다.

## 환경

직접 확인한 환경은 Python 3.12.14, PyTorch 2.11.0+cu128, torchvision 0.26.0+cu128, CUDA 12.8, RTX 4090이다. CPU 기준 별도 검사도 수행했다. Python 의존성은 torch·torchvision·numpy·fvcore다. CUDA용 torch는 공식 PyTorch 설치 안내에 맞추어 설치한다.

## 공식 자료

고정 모델 카드와 구조는 https://huggingface.co/minchul/cvlface_adaface_ir101_webface12m/tree/54f602a0737bd1ee4a4e7e9fd089a485f397fefd 에 있다. 그 안의 models/iresnet/model.py와 pretrained_model/model.pt를 다운로드하고 코드·가중치·학습 데이터 이용 조건을 확인한다. 이 원본 구조는 fvcore.nn을 import하므로 해당 의존성을 설치해야 한다. 추가 랜드마크나 얼굴 정렬은 사용하지 않는다.

구조 파일의 SHA-256은 e31be55c60b538c15151887e911b7535e2f0e1114a13427ba06483e1cd2a63f9, 가중치는 e312d79222d28027f146ed495e182e48fe0dddf404cdbbdabcccdbdd07cc3758이다. loader가 실제 적재 전에 대조한다. 다른 버전 소스나 가중치를 대신 사용한 결과를 같은 실험으로 집계하지 않는다.

## 명령

작업 디렉터리는 이 문서의 상위인 1차 폴더다. 다음 인자의 경로를 실제 로컬 파일과 새 출력 디렉터리로 지정한다. 기존 출력 폴더는 덮어쓰지 않는다.

```powershell
python -B -X utf8 -m unittest discover -s tests -v
python -B -X utf8 tools/run_stage1.py --vendor-source ../work/vendor/cvlface/models/iresnet/model.py --checkpoint ../models/adaface_ir101_webface12m.pt --output ../work/private/new-diagnostic-run --private-temp ../work/private --device cuda --threads 4
```

CPU 기준 실행은 새로운 출력 폴더와 --device cpu를 지정한다. 이 옵션은 기본 진단 장치를 지정하며 명시적인 cuda_fp32·cuda_fp16·cuda_bfloat16·cpu_cuda_parity 항목은 이름에 명시된 장치를 사용한다. CUDA가 없는 장치의 미지원 결과를 CUDA 실행 성공과 동일하게 보고하지 않는다.

## 판정

run02의 실제 결과는 29통과·channels_last 1미지원·실패0이었다. channels_last는 공식 view 기반 Flatten 제약으로 사용하지 않으며 NCHW를 유지한다. 30개 항목을 30회의 학습으로 해석하지 않는다. 세 클래스 헤드의 합성 경사 검사에서 정상·양성·악성 임상 정확도는 계산하지 않는다.

평가 조건·수치 허용 오차·미지원 기준은 configs/stage1_cases.json과 src/diagnostics.py에 있다. 실패 원문과 수정 전 실행은 비공개 운영 기록에 보존하고 공개 보고서에 발생 원인·수정 범위를 기록했다.
