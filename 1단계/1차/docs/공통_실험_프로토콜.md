# 공통 실험·검증 프로토콜

확인일: 2026-11-03. 시험 결과를 보기 전 고정하는 설계이며 아직 실행 결과가 아니다.

## 단계와 차수

실제 프로젝트는 E:/2026/Face CT Transfer Project에 저장한다. 최상위에는 1단계·2단계·3단계를 두고 각 단계 아래 1차 및 해당 단계의 data·models·work를 둔다. 회차 01~30은 차수와 별개다. 같은 요청의 수리 때문에 임의로 차수를 늘리지 않는다. 기존 D드라이브 폐암 자료는 읽기만 하며 새 프로젝트에서 원본을 덮어쓰지 않는다.

## 통일할 비교 조건

환자 키·출처·검사 시점·라벨 근거·원본 해시를 기록하고 정확 중복과 의심 근접 중복을 확인한다. 다중 촬영·결절·슬라이스는 같은 환자 그룹으로 묶는다. 익명 환자 키는 분할·중복 방지에만 사용하며 예측하지 않는다.

1단계의 모델 로딩·합성 입력 검사는 CT 진단 정확도 실험과 구분한다. 데이터가 확보되기 전 7-fold 성능을 만들지 않는다. 이후 두 단계는 같은 고정 환자 분할을 공유한다. 환자 키가 확인되지 않는 IQ JPG는 환자 독립 검증으로 표현하지 않으며, 환자 단위 주 분석의 대체 자료로 사용하지 않는다.

CT는 DICOM의 RescaleSlope/Intercept로 HU 변환하고, 사전에 정한 폐 윈도우 및 공간 크기를 적용한다. 2차원 얼굴 백본의 입력은 RGB 3×112×112, 정규화 [-1,1]로 통일한다. 종양 ROI와 전체 흉부를 혼합해 세 클래스를 만들지 않는다. 공간 규격·샘플링 위치·정규화는 학습·검증·시험에서 동일하게 유지한다.

## 분할과 학습

환자별 클래스 수가 충분하면 StratifiedGroupKFold 7개 외부 fold를 고정한다. 각 외부 학습 fold 안에서 환자 단위 검증 자료를 다시 분리한다. 외부 시험 fold는 조기 종료·하이퍼파라미터 선택·임계값·온도 보정에 사용하지 않는다. 환자 수가 불충분하거나 fold별 클래스 누락이 생기면 실행 전에 차단하고 사유를 보고한다.

모든 비교는 동일한 fold·초기 시드·데이터 노출량·최대 epoch·최적화 단계 예산을 사용한다. 기본 AdamW·가중치 감쇠·warmup/cosine 스케줄·검증 macro-F1 기준 조기 종료·최적 체크포인트 복원을 사용한다. 클래스 가중치는 학습 fold에서만 계산한다. 불균형 샘플러와 가중 손실을 동시에 적용하는 것은 별도 실험 근거 없이는 기본값으로 두지 않는다.

학습 전용 증강은 회전·크기/위치 변화 등 진단 의미를 보존하는 범위에서 고정한다. 얼굴 검출·정렬·랜드마크를 CT에 임의 적용하지 않는다. 필터 강도와 병변 정보를 없앨 수 있는 강한 증강을 기본 설정에 섞지 않는다. MixUp·CutMix·라벨 평활화·TTA·앙상블은 각각 효과를 분리해서 평가할 비교 항목이며 무조건 조합하지 않는다.

FP32를 기준으로 AMP·배치 크기·데이터 로더 처리량·최대 메모리를 비교한다. 작은 배치에서의 BatchNorm 동작과 동결 백본의 통계 갱신을 검사한다. 가중치 적재는 weights_only=True와 strict=True, 원본 SHA-256 대조를 사용한다. 무작위 초기화·얼굴 사전학습·일반 영상 사전학습의 비교가 같은 예산에서 가능한 경우에만 수행한다.

## 평가와 통계

OOF 예측을 모아 정확도·균형 정확도·macro/weighted-F1·클래스별 precision/recall·one-vs-rest ROC-AUC·혼동행렬을 계산한다. 지원되지 않는 지표는 임의의 0이나 1로 채우지 않는다. 환자 단위 부트스트랩 신뢰구간과 동일 환자 대응 비교를 사용하고, 여러 기법 비교에는 다중비교 보정을 적용한다. fold 표준편차를 독립 표본의 신뢰구간으로 바꾸어 쓰지 않는다.

보정도는 Brier score·NLL·사전에 고정한 bin의 ECE로 평가한다. 온도 보정은 검증 자료에서만 학습한다. 외부 데이터는 주 분석과 동일한 임상 라벨 정의가 확인되는 범위에서 평가하며, 이진 자료에 정상 클래스의 외부 성능을 만들지 않는다.

3단계는 먼저 원본으로 학습한 동결 모델의 필터 강건성을 평가한다. 필터별 재학습은 다른 질문이므로 별도 명시한 실험으로만 수행한다. 가우시안 블러·모자이크·중앙값 필터·양자화·JPEG 압축을 각각 10조건으로 정의하고 원본 기준을 포함한다. 필터 강도 단위와 적용 해상도를 함께 기록한다. 영상 유사도 감소나 정확도 저하는 재식별 방지나 익명성의 증명이 아니다.
