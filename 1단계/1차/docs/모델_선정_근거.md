# 얼굴 사전학습 모델 선정 근거

조사일: 2026-11-03. 아래 얼굴 성능은 저자 보고값이며 이 연구의 CT 측정값이 아니다.

주후보는 AdaFace IR101 WebFace12M이다. RGB 3×112×112 입력과 512차원 출력, 추가 얼굴 랜드마크 없는 구조, 실제 다운로드 가능한 학습용 state_dict 및 고정 버전 소스를 확인했다. 얼굴 벤치마크에서 가장 큰 수치만 가진 모델을 CT 최적 모델이라고 가정하지 않는다. 이번 선정은 강력한 공개 모델 가운데 재현성과 CT 전이의 구조적 적합성을 함께 고려한 선택이다.

| 후보 | 공식 근거 | 선정 시 판단 |
|---|---|---|
| AdaFace IR101 WF12M | https://huggingface.co/minchul/cvlface_adaface_ir101_webface12m | 주후보. 실제 가중치와 고정 버전 구조 제공 |
| LVFace-B Glint360K | https://huggingface.co/bytedance-research/LVFace | 2025 공개 비교 후보. 논문 최고 모델과 공개 가중치를 구분해야 함 |
| ViT-B KP-RPE WF12M | https://huggingface.co/minchul/cvlface_adaface_vit_base_kprpe_webface12m | 얼굴의 5개 keypoint 입력 필요. CT에 임의의 얼굴 keypoint를 만들지 않음 |
| ArcFace iResNet100 | https://github.com/deepinsight/insightface/tree/master/recognition/arcface_torch | 강력한 기존 기준. ONNX만 제공되는 파일을 학습용 체크포인트로 오표기하지 않음 |

동일 KP-RPE 논문 Table 4에서 WF12M IR101과 KP-RPE의 IJB-C TAR@FAR=1e-4는 각각 97.66%, 97.82%이다. 랜드마크 사용 등 평가 조건을 포함한 얼굴 결과다. LVFace-B Glint 모델 카드의 97.70%와는 학습 자료·방법이 달라 직접 순위를 단정하지 않는다. 원논문: https://arxiv.org/html/2403.14852v1

원래 AdaFace 구현은 BGR을 사용하지만 이번 CVLFace 체크포인트의 설정은 RGB이다. 모델 이름만 보고 전처리를 재사용하지 않는다. https://github.com/mk-minchul/AdaFace

주후보 고정 revision은 54f602a0737bd1ee4a4e7e9fd089a485f397fefd이다. 가중치 실제 다운로드 크기 261111273바이트, SHA-256 e312d79222d28027f146ed495e182e48fe0dddf404cdbbdabcccdbdd07cc3758로 공식 LFS 메타데이터와 일치했다. 이 확인은 원출처의 무결성 대조이며 사전학습 성능을 재현했다는 뜻이 아니다.

가중치: https://huggingface.co/minchul/cvlface_adaface_ir101_webface12m/resolve/54f602a0737bd1ee4a4e7e9fd089a485f397fefd/pretrained_model/model.pt

구조: https://huggingface.co/minchul/cvlface_adaface_ir101_webface12m/blob/54f602a0737bd1ee4a4e7e9fd089a485f397fefd/models/iresnet/model.py

코드의 MIT 라이선스가 가중치와 학습 데이터 전체의 상업적 이용 허용을 뜻하지 않는다. CVLFace 모델 카드의 학습 데이터 이용 조건과 LVFace의 비상업 연구용 가중치 조건을 별도로 기록한다. 이 프로젝트는 연구용으로 사용하며 가중치를 재배포하지 않는다. CVLFace 공식 코드: https://github.com/mk-minchul/CVLface/tree/308142aa50adf2e187711354f7524635d3414f1e

검색에서 확인한 최신 후보의 전 범위 성능을 직접 비교하지 않았으므로 세계 최고·최초 연구·CT 최고 성능을 주장하지 않는다. 실제 CT 비교는 2단계 결과로 판단한다.
