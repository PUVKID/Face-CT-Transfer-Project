# 얼굴 사전학습 모델의 폐 CT 전이 연구 요구사항

확인일: 2026-11-03. 이 문서는 연구 계획이며 관측 결과가 아니다.

## 목적과 범위

1단계에서 공개 얼굴 사전학습 모델의 성능 근거·이용 조건·가중치·전이학습 동작을 검토한다. 실제 인물을 식별하거나 환자 번호를 예측하지 않는다. 2단계의 예측 대상은 정상·양성·악성이다. 3단계에서 다섯 필터의 열 수준에서 분류 성능을 비교한다.

## 완료 조건

- 단계마다 서로 다른 30개 검토 또는 실험을 실시하고, 실제 설정·측정·실패·한계를 보존한다.
- 각 회차별 보고서와 결과를 먼저 로컬 저장하고 독립 검토 뒤 GitHub에 반영한다. 재사용한 자료나 반복 검사는 독립 학습으로 부풀리지 않는다.
- 얼굴 공개 벤치마크의 저자 보고값과 이 컴퓨터의 직접 측정을 분리한다. 세계 최고나 CT 최고 성능을 검증 없이 주장하지 않는다.
- 사전학습 가중치와 무작위 초기화를 구별한다. 합성 입력의 동작 검사와 실제 CT의 분류 실험을 구별한다. ONNX 추론을 종단간 미세조정으로 표현하지 않는다.
- 외부 코드와 가중치의 이용 조건을 별도로 확인하고 원본 버전과 SHA-256을 기록한다. 얼굴·의료 원영상·가중치·개인 운영 기록은 공개 저장소에 넣지 않는다.
- 2단계는 환자 단위 분할 및 출처 간 중복 검사를 우선한다. 환자 매핑이 불명확한 영상은 탐색 평가로만 보고하고 확증 환자 성능을 주장하지 않는다.
- 정상·양성·악성 라벨의 정의와 근거를 출처별로 보존한다. 방사선과 의사의 악성도 점수, 암 환자 컬렉션 포함 여부, 병리 확진을 혼동하지 않는다. 자료를 단순히 합쳐 출처를 예측하는 누수를 만들지 않는다.
- 대규모 신규 공개 CT는 용량과 라벨 접근을 검증하고 단계적 다운로드한다. 동일 자료의 재다운로드는 신규 환자 수로 세지 않는다. 기존 작업·GPU 프로세스를 중단하지 않는다.
- 검증·원격 반영이 미완료이면 완료 수와 남은 수를 정직하게 보고한다. 30개 보고서와 30회 원격 반영은 실제 확인한 것만 집계한다.

## 3단계 사전 정의

가우시안 블러의 표준편차는 [0,1,2,4,8,16,32,64,128,256]으로 둔다. 모자이크는 블록 한 변 [1,2,4,8,16,32,64,128,256,512] 픽셀로 정의한다. 나머지 세 필터의 종류·단위·수준은 원본 CT 크기와 분류 파이프라인을 확인한 뒤 시험 결과를 보기 전에 고정한다. 강도 0은 원본과 일치해야 한다. 유사도 감소를 익명성 보장으로 해석하지 않는다.
