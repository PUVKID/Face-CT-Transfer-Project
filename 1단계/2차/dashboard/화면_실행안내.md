# 얼굴 연구 화면 실행

2차 폴더에서 프런트엔드 의존성을 `dashboard/frontend`의 `pnpm install --frozen-lockfile`로 설치하고 `pnpm build`로 화면을 빌드합니다. 기존 제공 빌드가 있다면 별도 빌드 없이 서버가 이를 제공합니다.

실제 상태와 허용 로그가 있는 기존 폴더를 `FACE_CT_STATE_DIR` 환경변수에 지정한 뒤 2차 폴더에서 `python dashboard/실시간화면_실행.py --port 8892`를 실행합니다. 지정하지 않거나 폴더가 없으면 종료합니다. 이 진입점은 기존 서버의 프로세스 기록 파일을 교체하지 않습니다. 화면은 `http://127.0.0.1:8892/`에서 열 수 있습니다.

테마 CSS를 다시 생성할 때는 [Astryx Theme Engine](https://github.com/PUVKID/AstryxThemeEngine)의 Rust 도구를 빌드하고 실행 파일의 실제 경로를 `ASTRYX_THEME_EXECUTABLE`에 지정한 뒤 2차 폴더에서 `python 테마생성.py`를 실행합니다. 프런트엔드 의존성도 먼저 설치해야 합니다. 상태·모델·데이터와 Rust 실행 파일은 공개 소스에 포함되지 않습니다.
