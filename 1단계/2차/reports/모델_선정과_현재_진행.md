# 새 얼굴 모델 선정과 검증 진행

현재 상태는 문서 하단의 실제 획득·정렬 추가 기록을 기준으로 읽으며, 앞선 미검증 문구는 각 기록 시점의 관측입니다.

## 연구 목적

공개 사전학습 얼굴 인식 모델의 원래 얼굴 평가 성능을 먼저 직접 측정하고, 이후 폐 CT 분류 전이와 영상 필터 영향을 분석합니다. 이번 1단계 2차는 모델 선정·실제 얼굴 벤치마크 재현·실시간 대시보드입니다. 기존 1차의 합성 입력 진단은 실제 얼굴 정확도 재현으로 간주하지 않습니다.

## 선택 모델과 비교 범위

TopoFR의 **Glint360K 학습 R200** 공개 체크포인트를 선택했습니다. [저자 저장소](https://github.com/DanJun6737/TopoFR)와 [원논문 Table 2](https://arxiv.org/html/2410.10587v1)의 해당 행을 대조했습니다.

| 평가 | 저자 보고 | 이 기록 작성 시 직접 측정 |
|---|---:|---|
| IJB-C TAR, FAR=0.0001 | 97.84% | 미측정 |
| IJB-C TAR, FAR=0.00001 | 96.71% | 미측정 |
| LFW 정확도 | 99.87% | 미측정 |

선택 범위는 실제 공개 학습 가능 가중치를 확인한 후보의 동일 IJB-C FAR 조건 비교입니다. 모든 상용 시스템과 모든 미공개 가중치를 포함한 절대 1위라고 주장하지 않습니다. TopoFR의 다른 학습 자료로 얻은 더 높은 행을 이 체크포인트의 성능으로 쓰지 않습니다.

[NIST FRTE](https://pages.nist.gov/frvt/html/frvt11.html)는 여러 평가 조건과 개발사 제출 알고리즘을 비교합니다. 이 순위를 연구자가 내려받아 학습할 수 있는 공개 가중치 순위로 해석하지 않습니다. 논문 최고 행과 실제 공개 버전이 다른 후보, 가중치를 확인하지 못한 후보는 같은 조건의 직접 재현 후보와 구분합니다.

## 실제 측정의 성공 조건

- 가중치의 전체 길이·형식·엄격 적재를 확인하고 최초 전체 SHA-256을 고정합니다. 공식 체크섬이 제공되지 않았다면 로컬 해시 고정을 저자 체크섬 일치라고 표현하지 않습니다.
- LFW는 6,000쌍·10-fold의 얼굴 검증을 수행합니다. 정렬기·버전·가중치 해시·얼굴 선택과 검출 실패 정책을 먼저 고정합니다. 새로 정렬한 원본과 저자가 사용한 정렬 입력의 차이를 밝힙니다.
- 저자 코드의 정규화·뒤집기·거리·임계값 그리드·fold 순서·동률 규칙을 대조합니다. 시험 fold로 임계값이나 모델을 선택하지 않습니다.
- IJB-C는 이미지 식별자·정렬 좌표·template·media·평가쌍의 대응을 검사하고 저자의 특징 집계와 TAR/FAR 산출 규칙을 고정합니다.
- LFW 결과만으로 주 평가인 IJB-C 재현을 완료했다고 주장하지 않습니다. 입력 판본이나 평가 규칙이 다르면 차이를 함께 보고합니다.

## 현재 구현의 증거와 한계

초기 백엔드 검사 13개가 통과했습니다. 다운로드 재개와 해시, 압축 경로 이탈 방지, 평가 임계값 분리, template 집계와 읽기 전용 API를 검사했습니다. 프런트 초기 빌드와 표시 형식 검사 5개도 통과했습니다. 이는 실제 모델 정확도나 전체 시스템의 독립 검증 완료를 뜻하지 않습니다.

대시보드는 실제 상태 API로 다운로드·평가·GPU·기법·로그를 표시하고 논문 수치와 실측을 구분합니다. 초기 구현 이후 실제 브라우저 확인과 독립 최종 검증이 남아 있습니다. 미측정 성능·학습 곡선·진행률은 채우지 않습니다.

AdaFace 기반 기존 CT 실행은 중단하고 원본·체크포인트·부분 결과를 보존했습니다. 새 얼굴 모델의 재현 검토를 마친 뒤 새 차수의 CT 실험으로 진행합니다. 진행 중인 의료 자료 수집은 별도 작업으로 구분합니다.

## 공개 범위

코드·설정·집계 기술 보고서만 공개합니다. 원본 얼굴·CT 영상, 개별 예측·특징·가중치와 운영 기록은 제외합니다. 가중치와 자료의 이용 조건은 각각 확인하며 코드 저장소의 라이선스를 연결된 가중치 전체의 재배포 허가로 확대하지 않습니다. 이 기록은 진행 기술 보고서이며 논문 원고나 임상 검증 결과가 아닙니다.
