# 🧪 TopoFR 실제 얼굴 성능 재측정 결과

**공식 MS1MV2 정렬 LFW에서 6,000쌍을 모두 평가한 10fold 평균 정확도는 99.85%입니다.** 저자 보고 99.87%와 차이는 −0.02%p입니다. 저장한 원본·좌우반전 특징에서 별도 NumPy 계산으로 10개 fold의 정확도와 임계값을 전부 재계산해 일치를 확인했습니다.

## 고정한 평가 방식

제공된 112×112 RGB 영상을 검증해 입력하고 얼굴 재검출·크기변환·재정렬은 하지 않았습니다. RGB CHW를 [-1,1]로 정규화하고 원본과 좌우반전의 FP32 특징을 합한 뒤 L2 정규화했습니다. AMP와 TF32는 사용하지 않았습니다. 원저자 고정 소스와 공개 가중치의 전체 텐서를 엄격하게 적재했으며 학습이나 온도 교정은 하지 않았습니다.

연속 600쌍씩 고정 10fold를 사용했습니다. 각 시험 fold와 분리된 나머지 5,400쌍에서 squared-L2 임계값 0~3.99, 간격 0.01의 정확도를 비교하고 첫 번째 최대값을 선택했습니다. 시험 fold로 임계값을 고르거나 결과를 본 뒤 전처리를 바꾸지 않았습니다. 전체 6,000쌍이 정확히 한 번씩 시험 평가에 포함됐습니다.

## 독립 검증과 해석

실행 전 코드 검사 88개, 프런트 빌드와 표시 검사 19개가 통과했습니다. 실행 후에는 구현자와 다른 검증자가 입력·캐시·특징의 전체 해시, 12,000×2×512 FP32 배열과 유한값, 재개 영수증의 완료 위치 및 코드·모델·자료 결합을 확인했습니다. 제품의 지표 계산 함수를 호출하지 않고 별도 NumPy 거리와 임계값 계산으로 5,991정답·9오류 및 10fold 수치를 재계산했습니다. 코드 검사 횟수는 독립 연구나 학습 횟수로 세지 않습니다.

99.85%는 저자 보고에 가까운 보조 벤치마크 실측입니다. 저자 당시 LFW bin의 전체 SHA와 당시 MXNet 디코더 대비 현재 OpenCV 디코더의 픽셀 동일성은 확인하지 못했습니다. bin에 영상 이름이 없어 인물 ID를 독립 대조했다는 주장도 하지 않습니다. 따라서 저자 조건의 완전 동일 재현 또는 통계적 동등성 입증으로 표현하지 않습니다.

모델 선정의 주 비교 지표인 **IJB-C TAR@FAR=1e-4의 97.84%는 여전히 저자 보고입니다.** IJB-C 원자료는 외부 배포 할당량으로 확보하지 못했고 LFW 결과로 이를 대체하지 않았습니다. 이번 결과는 임상 성능·의료 영상 성능·프라이버시 보호나 익명성을 검증하지 않습니다. AdaFace의 중단된 CT 결과와 섞지 않습니다.
