### LEVEL 1·6,000 쌍과 10fold 임계 값 선택

**쌍은 두 사진이 같은 사람인지 묻는 한 문제**입니다. 임계 값은 얼마나 닮으면 같다고 할지 정하는 문턱이며, 시험할 문제를 보며 정하지 않도록 다른 5,400 쌍에서 고릅니다. 입력 횟수와 실제 사람 수를 구분해 결과를 읽으세요.

| 조건·자료 | 의미와 확인 방법 |
| --- | --- |
| <a id="layout18-table-1-row-1"></a> 시험 단위 | TopoFR-R200 Glint360K를 공식 MS1MV2 제공 정렬 LFW의 6,000 쌍으로 평가했습니다.<br>영상 입력 12,000회는 같은 사진의 재사용을 포함하며 고유 사진이나 인물 12,000개를 뜻하지 않습니다. |
| <a id="layout18-table-1-row-2"></a> 10fold | 평가 쌍을 열 묶음으로 나눕니다.<br>매번 시험할 묶음과 분리된 5,400 쌍에서 같은 사람으로 판단할 거리 임계 값을 고르고, 남긴 쌍을 평가해 6,000 쌍을 한 번씩 시험합니다. |

### LEVEL 1 · 달라진 내용과 차수 관계

같은 1 단계 2차에서 공식 정렬 입력 캐시와 평가 실행을 보완해 LFW를 측정했습니다. 과거 준비 커밋의 미측정·실패는 당시 기록으로 보존합니다.

얼굴에서 익힌 무늬가 CT 분류에도 도움이 되는지 묻습니다. 모델이 파일을 잘 읽는 것과 사람·질병을 잘 구분하는 것은 다른 확인입니다. 자료에 정상 사진이 없는 경우 억지로 정상·양성·악성 세 종류로 합치지 않습니다.

### LEVEL 1 · 입력과 실행 조건

- 원보고 IJB-C TAR 97.84%@FAR=1e-4, 96.71%@FAR=1e-5와 LFW 99.87%를 각각 구분합니다.
- 가중치 수신·최초 로컬 SHA-256 고정과 strict 적재는 다른 확인입니다. 공식 전체 체크섬은 미제공입니다.
- 12:08 첫 strict CPU 적재는 필수 생성 인자 문제로 실패했습니다. 저자 설정을 복원한 뒤 12:14:53 CPU strict 적재와 백 엔드 검사 19개가 통과했으나 GPU 얼굴 추론·정확도는 미측정입니다.
- IJB-C 배포는 Drive 할당량 초과 HTML로 차단됐으며 실제 영상 확보로 처리하지 않습니다.
- 기존 AdaFace CT 실행은 사용자 중단·보존 상태입니다. 현재 모델의 직접 실험 결과로 섞지 않습니다.

### LEVEL 1 · 처리 절차

React·Vite와 실제 Three.js 3D를 사용합니다. 원 보고와 실측 탭, 단계 선택, 정지/재생, 로그 출처·오류 필터·갱신, 오래된 상태·사용자 중단·외부 대기를 분리합니다. 생성 이미지를 기능 화면으로 넣지 않습니다. 나눔 고딕 Bold700 파일과 OFL을 포함합니다.

실제 브라우저 동작과 형식·프로세스 문구·로그 회귀 검사 19개·빌드를 확인했습니다.

모바일 viewport와 모션 축소 환경의 실제 렌더는 미확인입니다.

API는 `127.0.0.1`의 읽기 전용이며 `/api/status`, 제한된 `/api/logs`만 제공합니다.

임의 명령·파일 입력이나 작업 시작 버튼은 없습니다.

프런트 작업 위치는 `dashboard/frontend`입니다. Node와 pnpm을 준비한 뒤 다음 명령을 사용합니다. 설치 캐시는 같은 프로젝트의 `1단계/work/stage1_revision2`에 두며 모델·데이터·의존성은 저장소에서 배포하지 않습니다.


서버는 빌드된 `dashboard/frontend/dist`를 제공합니다. CPU strict 가중치 적재는 통과했지만 평가 코드는 실제 얼굴 추론·평가와 독립 검증이 끝나기 전까지 얼굴 성능 재현 완료로 취급하지 않습니다.

[API 계약](docs/상태_API.md) · [화면 구현 기준과 검사 범위](docs/대시보드_디자인.md)

얼굴·CT 영상·개별 결과·가중치·임베딩·인증값·운영 로그는 공개하지 않습니다. 이 자료는 기술 진행 보고서이며 논문 원고나 임상 결과가 아닙니다.

처음에는 실제 LFW 결과와 당시 준비 기록을 나누어 읽습니다. 화면의 로그와 상태는 읽기 전용입니다. 버튼이 있다고 학습을 새로 시작하는 앱은 아닙니다.

### LEVEL 1 · 결과를 확인하는 방법

TopoFR-R200 Glint360K를 공식 MS1MV2 제공 정렬 LFW의 6,000 쌍으로 평가해 10fold 평균 정확도 **99.85%**를 얻었습니다.

정답 5,991·오답 9(동일인 오거부 9·타인 오수락 0), fold 표준 편차 0.203443%p(ddof =0)입니다. 표준 편차는 신뢰구간이 아닙니다. 저자 보고 99.87%와 차이는 −0.02%p입니다.

영상 입력 12,000회는 중복을 포함하며 고유 영상·인물 12,000개를 뜻하지 않습니다.

### LEVEL 2 · 결과를 확인하는 방법

TopoFR-R200 Glint360K를 공식 MS1MV2 제공 정렬 LFW의 6,000 쌍으로 평가해 10fold 평균 정확도 **99.85%**를 얻었습니다.

정답 5,991·오답 9(동일인 오거부 9·타인 오수락 0), fold 표준 편차 0.203443%p(ddof =0)입니다. 표준 편차는 신뢰구간이 아닙니다. 저자 보고 99.87%와 차이는 −0.02%p입니다.

영상 입력 12,000회는 중복을 포함하며 고유 영상·인물 12,000개를 뜻하지 않습니다.

실제 GPU 평가는 15:52:20~16:01:53 한국 시각에 FP32·batch4·원본/좌우 반전 특징 합으로 완료했습니다. 시험 fold와 분리한 5,400 쌍에서 임계 값을 고르고 6,000 쌍을 한 번씩 평가했습니다.

재학습·삭제쌍·결과에 맞춘 전처리 변경 없이 저장 특징에서 구현자와 다른 검증자가 별도 NumPy 거리·임계값·10fold 수치를 재계산해 일치를 확인했습니다.

저자 당시 bin의 전체 SHA와 MXNet/OpenCV 디 코딩의 픽셀 동일성은 미확인입니다. 따라서 완전히 같은 입력 재현·통계적 동등성·세계 절대 최고를 주장하지 않습니다.

주 비교 지표인 **IJB-C TAR97.84%@FAR=1e-4는 계속 저자 보고**이며 IJB-C는 외부 할당 량 대기입니다. LFW 실측으로 IJB-C·의료/임상·전체 단계 완료를 대체하지 않습니다.

같은 1 단계 2차의 후속 수정으로 제한 primitive 로더·공식 입력 캐시·평가 실행과 관련 검사·문서를 반영했습니다.

새 차수나 30회 연구를 만들지 않았습니다.

원형 26 파일과 기존 YuNet70 실패 집계는 보존하고 freeze10 백 엔드 28 파일·동일 프런트 18 파일을 사용합니다.

실제 얼굴/CT·개별 특징·예측·점수·가중치·운영 로그는 공개하지 않습니다.

논문 원고 없이 기술 진행 보고서와 익명 집계만 공개합니다.

10fold 평균 99.85%는 저자 보고 99.87%보다 −0.02%p입니다. 같은 사람을 다르다고 한 9건, 다른 사람을 같다고 한 0건입니다. fold 표준 편차 0.203443%p는 신뢰구간과 다릅니다.

### LEVEL 2 · 주의할 범위

아래 미측정·미실행·개발 보류 문구는 준비 커밋 f221d44 시점의 기록입니다. 위 실측 및 후속 검증 결과와 구분합니다.

### LEVEL 4 · 결과를 확인하는 방법

TopoFR-R200 Glint360K를 공식 MS1MV2 제공 정렬 LFW의 6,000 쌍으로 평가해 10fold 평균 정확도 **99.85%**를 얻었습니다.

정답 5,991·오답 9(동일인 오거부 9·타인 오수락 0), fold 표준 편차 0.203443%p(ddof =0)입니다. 표준 편차는 신뢰구간이 아닙니다. 저자 보고 99.87%와 차이는 −0.02%p입니다.

영상 입력 12,000회는 중복을 포함하며 고유 영상·인물 12,000개를 뜻하지 않습니다.

실제 GPU 평가는 15:52:20~16:01:53 한국 시각에 FP32·batch4·원본/좌우 반전 특징 합으로 완료했습니다. 시험 fold와 분리한 5,400 쌍에서 임계 값을 고르고 6,000 쌍을 한 번씩 평가했습니다.

재학습·삭제쌍·결과에 맞춘 전처리 변경 없이 저장 특징에서 구현자와 다른 검증자가 별도 NumPy 거리·임계값·10fold 수치를 재계산해 일치를 확인했습니다.

저자 당시 bin의 전체 SHA와 MXNet/OpenCV 디 코딩의 픽셀 동일성은 미확인입니다. 따라서 완전히 같은 입력 재현·통계적 동등성·세계 절대 최고를 주장하지 않습니다.

주 비교 지표인 **IJB-C TAR97.84%@FAR=1e-4는 계속 저자 보고**이며 IJB-C는 외부 할당 량 대기입니다. LFW 실측으로 IJB-C·의료/임상·전체 단계 완료를 대체하지 않습니다.

같은 1 단계 2차의 후속 수정으로 제한 primitive 로더·공식 입력 캐시·평가 실행과 관련 검사·문서를 반영했습니다.

새 차수나 30회 연구를 만들지 않았습니다.

원형 26 파일과 기존 YuNet70 실패 집계는 보존하고 freeze10 백 엔드 28 파일·동일 프런트 18 파일을 사용합니다.

실제 얼굴/CT·개별 특징·예측·점수·가중치·운영 로그는 공개하지 않습니다.

논문 원고 없이 기술 진행 보고서와 익명 집계만 공개합니다.

YuNet 정렬 7,631 성공·70 실패·다중 얼굴 511의 관측은 인식 정확도가 아닙니다. 해당 준비는 protocol_unmet이었고 이후 공식 정렬 입력으로 LFW를 평가했습니다. 실패 기록과 성공 평가를 같은 실행으로 합치지 않습니다.

## 실제 LFW 평가 결과 — 2026-11-03

TopoFR-R200 Glint360K를 공식 MS1MV2 제공 정렬 LFW의 6,000 쌍으로 평가해 10fold 평균 정확도 **99.85%**를 얻었습니다.

저자 당시 bin의 전체 SHA와 MXNet/OpenCV 디 코딩의 픽셀 동일성은 미확인입니다. 따라서 완전히 같은 입력 재현·통계적 동등성·세계 절대 최고를 주장하지 않습니다.

같은 1 단계 2차의 후속 수정으로 제한 primitive 로더·공식 입력 캐시·평가 실행과 관련 검사·문서를 반영했습니다.

새 차수나 30회 연구를 만들지 않았습니다.

원형 26 파일과 기존 YuNet70 실패 집계는 보존하고 freeze10 백 엔드 28 파일·동일 프런트 18 파일을 사용합니다.

실제 얼굴/CT·개별 특징·예측·점수·가중치·운영 로그는 공개하지 않습니다.
