**사용자 최신 정정: AdaFace 기반 작업을 중단하고 외부에서 최고 성능으로 평가된 새 얼굴 모델을 가져와 실제 얼굴 성능 재현을 1 단계로 먼저 수행한다.** 모델별 동일 평가조건과 공개 가중치 버전을 확인하며 근거 없는 세계 최고 주장을 하지 않는다.

대시보드에서 현재상황·기법·학습/평가 진행과 자원·로그를 실제 실행에 연결한다.

## 얼굴 실험

주 비교 조건은 IJB-C TAR@FAR=1e-4, 보조는 1e-5/1e-6.

현재 확인 공개 후보 중 TopoFR-R200 Glint360K 저자보고 97.84%/96.71%, KP-RPE97.82%, LVFace-B97.70%를 같은 FAR로 구분한다.

논문 전용/미공개 GIF98.42%·LVFace WebFace42M 수치를 다른 공개 가중치 성능으로 대체하지 않는다.

최종 모델 다운로드는 원저자 연결/정확 버전/형식/출처 확인 뒤 수행한다.

LFW6000 쌍/10fold는 보조 정확도 평가이며 IJB-C 재현으로 표현하지 않는다.

얼굴 검출·5점 정렬·색 순서·112 입력/정규화·flip/template/faceness/score normalization 조건을 원 평가와 대조한다.

모델 가중치 strict 적재와 안전한 weights_only 경계를 유지한다.

원 데이터/모델 바이트를 보존하며 직접 측정/원 보고/자료 미확보를 각각 기록한다.

벤치마크/가중치 획득 전 정확도 0%가 아니라 미측정으로 표시한다.

## 화면과 상태 계약

선택 근거/모델·가중치버전/원보고값과 직접 값, 현재 작업·단계 흐름 3D, 데이터 파일별 수신/해시검증, GPU/메모리, epoch·batch·ETA(추정표시), 실제 평가 쌍/영상 진행, 적용 기법(계획/활성/미사용), 완료/중단/오류 로그를 보인다.

과거 AdaFace는 중단·보존으로만 구분한다.

그래프는 실제 시계열만 표시하고 없으면 빈 상태로 설명한다.

상태 API GET/api/status 및 제한된 GET/api/logs를 사용하며 프런트가 상대 URL로 주기 갱신한다.  
127.0.0.1전용, 임의 파일/명령/모델 실행 입력 없음. 소스가 없거나 시간이 오래 되면 stale/대기를 명시하고 가짜 정상 진행을 만들지 않는다.

운영 상태는 같은 프로젝트 상위 `work/stage1_revision2/status.json`에 저장하고 소스와 분리한다.  
필드 계약은 `docs/상태_API.md`에 고정하며 프런트는 읽기 전용으로 조회한다.

## 완료 검증

실제 얼굴 자료에서 원 보고값과 직접 측정 값 및 차이를 보고해야 실험 완료다.

데이터/접근 제약이면 미완료를 명시한다.

대시보드는 실제 API/오류·빈 상태/모바일·모션제어/3D/동작 을 브라우저로 확인하고 시안/렌더를 비교한다.

구현자와 별도 verifier의 검사·중앙 영수증 및 공개용 변경 기록 →커밋 →원격 gate를 거친다.

원본과 개인 운영 정보는 제외한다.
