# 얼굴 평가의 입력·지표 고정 규칙

주지표는 IJB-C TAR@FAR=1e-4이고 보조 조건은 1e-5·1e-6이다. LFW 고정 6000쌍 10fold는 별도 보조 정확도이며 IJB-C 완료나 세계 전체 최고 입증으로 쓰지 않는다. 저자 TopoFR Glint360K R200 행은 LFW99.87%, IJB-C97.84%@1e-4·96.71%@1e-5이다. 논문의 더 큰 학습 자료 행과 공개 가중치를 혼합하지 않는다.

## 원본 모델과 생성 인자

저자 소스 revision은 `5960a33220968e6f9f74adcffb3f1a4ca31f9a0a`다. `eval_ijbc_glint360k.py`의 호출과 `configs/glint360k_r50.py`를 대조해 R200을 `dropout=0, fp16=False, num_features=512, num_classes=360232`로 생성한다. 원래 클래스 중심 `weight[360232,512]`를 포함한 전체 state_dict 1808개를 삭제 없이 `weights_only=True`·CPU 역직렬화·strict 적재·형상/dtype/유한값 검사한다. 평가 forward는 `phase='infer'`이며 경사 계산과 학습을 하지 않는다. 공식 소스는 고정 Git blob과 대조하고 원문을 수정하지 않는다.

1214223369바이트 체크포인트의 최초 로컬 SHA-256은 `bf0fda461721273279f39688f834c81d4ec5e4b3465cd8946d324f555b025111`이다. 저자의 공식 모델 체크섬이 게시됐다는 뜻이 아니다. 모델 적재 검사 통과는 얼굴 정확도 측정이 아니다. Glint360K 공식 배포는 비상업 연구 용도를 명시하지만 TopoFR 체크포인트의 별도 라이선스나 재배포 권한까지 확인된 것은 아니다. 원본 가중치는 로컬 연구용으로만 사용하며 공개하지 않는다.

## LFW 독립 정렬 재측정

공식 scikit-learn이 연결한 Figshare 원본 `lfw.tgz`와 `pairs.txt`의 공식 SHA-256을 먼저 대조한다. 고정 pair 순서·영상 ID를 유지하고 pair에서 참조하는 고유 영상만 정렬한다. 안전 추출은 절대경로·상위경로·링크·특수파일·상한 초과를 거부하며 원본 및 기존 파일을 덮어쓰지 않는다.

정렬기는 OpenCV Zoo YuNet 2023mar, revision `48b10fa505aeb51fbd127fc60a5c660040e823b7`, 공식 LFS SHA-256 `8f2383e4dd3cfbb4553ea8718107fc0423210dc964f9f4280604804ed2552fa4`다. `opencv-python-headless==4.13.0.92`의 공식 Windows wheel SHA-256도 고정하며 의존성 업그레이드를 하지 않는다. CPU backend, score0.9·NMS0.3·topK5000을 고정한다. 다중 얼굴은 영상 중심과 bbox 중심의 제곱거리 최소, 동률은 큰 면적·높은 점수·좌표 사전순으로 선택한다.

YuNet 5점을 canonical `(38.2946,51.6963), (73.5318,51.5014), (56.0252,71.7366), (41.5493,92.3655), (70.7299,92.2041)`로 similarity 정렬한다. 최소제곱 해·OpenCV INTER_LINEAR·검정 border·112×112 RGB uint8을 사용한다. 검출/디코딩 실패가 하나라도 있으면 실패 영상 목록은 비공개로, 실패 수와 coverage는 집계로 보존한다. 해당 pair를 삭제하거나 임의 resize로 대체해 정확도를 만들지 않는다. `protocol_unmet`는 원인과 후속 방법 검토가 필요한 상태다.

이 입력은 저자 배포 aligned112/bin과 동일성이 확인되지 않았다. 따라서 결과명은 **YuNet 독립 정렬 LFW 재측정**이며 저자와 동일한 입력의 99.87% 재현이라고 주장하지 않는다. 저자와 같은 aligned/bin 정상 배포 경로는 추가 획득이 필요하다. 공식 InsightFace DataZoo의 LFW 목록은 확인했지만, 해당 페이지에서 독립 aligned LFW bin 다운로드 링크는 확인하지 못했다. 계정·폼·암호·할당량 제한을 우회하지 않는다.

입력 정규화는 RGB CHW FP32에서 `((x/255)-0.5)/0.5`다. 원본과 좌우반전의 원래 특징을 더한 뒤 float64에서 L2 정규화한다. squared-L2 거리, `np.arange(0,4,0.01)`, shuffle 없이 연속 600쌍씩 10fold, 나머지 5400쌍의 정확도 최대 임계값, 최초 argmax 동률 선택, 평균과 표준편차 `ddof=0`을 사용한다. 테스트 fold 라벨로 임계값을 고르지 않는다. AMP·TF32·학습·온도 교정을 적용하지 않는다. singleton 마지막 batch의 축을 유지한다.

## IJB-C 주평가의 준비 조건

현재 저자 연결 9169172480바이트 testsuite 다운로드는 Drive quota로 막혀 있다. prefix에서 IJBB 파일이 보였다는 이유로 IJBC 전체 확보나 라이선스 검토 완료를 주장하지 않는다. 전체 원본을 정상 획득한 뒤 archive의 원본 license/README와 배포조건을 검토하고 IJBC 3개 metadata 파일의 판본·해시를 고정해야 한다.

`ijbc_face_tid_mid.txt`와 `ijbc_name_5pts_score.txt`의 영상 이름·순서·개수, loose_crop 파일 존재, 유한한 5점과 faceness, template/media ID, 모든 genuine/impostor pair 참조를 대조한다. 라이선스 검토가 끝나기 전 `license_review_complete=false`를 유지한다. 현재 구현은 metadata 검사와 집계·ROC 규칙까지이며 전체 IJB-C 영상 추론 실행기는 아직 동결하지 않았다.

저자 IJB 규칙은 metadata의 5점으로 112 RGB 정렬, 원본+flip 특징 합, 특징 norm 유지, faceness 곱, 같은 video/media의 frame 평균, template 합, 최종 L2 정규화, template cosine이다. 저자 `sklearn.metrics.roc_curve` 기본 중간점 제거 후 ROC를 뒤집고 목표 FAR에 가장 가까운 점을 선택하므로 동일 FPR에서는 높은 TAR 동률이 선택된다. 원저자 nearest-FAR 수치와 목표 FAR 이하만 허용하는 보수적 수치를 함께 기록하고 실제 선택 FAR·threshold·genuine/impostor 쌍 수도 표시한다. 조건을 모델에 유리하게 바꾸지 않는다.

## 실행·증거 경계

준비와 평가는 별도 명령이며 소스 동결과 독립 검증 후 순서대로 시작한다. 준비 실패가 있어도 원본·coverage·실패 영수증을 보존한다. 특징 재개는 코드·가중치·정렬 캐시·pair 해시·장치·batch·Torch 버전에 결합하고 불일치하면 재결합하지 않는다. 완료 batch를 flush한 뒤 원자 재개 영수증을 저장한다. 실제 특징과 개별 영상 이름·점수는 공개하거나 대시보드로 제공하지 않는다.
