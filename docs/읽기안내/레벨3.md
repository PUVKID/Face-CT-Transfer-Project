<a id="guide-problem"></a>

## 문제와 주요 기능

분류 A는 LUNA25 공식 이 진 주석과 환자 그룹 7fold, B는 IQ의 정확화 소 중 복 그룹 7fold입니다. IQ 환자 매핑은 미확인입니다. 주석·검사 시점 수와 고유 환자·결 절 수를 구분해야 합니다.

<a id="guide-flow"></a>

## 입력·처리·출력

원래 모델의 특징과 적응 모델의 특징, fold별 head를 분리합니다. 공통 배치 16, 학습 가능한 backbone의 BF16 AMP, 동결 head·특징 추출·평가 FP32 조건을 확인합니다. 이전 실패와 재시작 시점을 함께 읽습니다.

<a id="guide-practice"></a>

## 실험과 사용 흐름

7일 상한은 최초 run의 종료 시각으로 고정하며 재개로 연장하지 않습니다. 중단한 특징·optimizer·RNG·배치 위치를 보존합니다. 07:12 재시작 관측의 완료 0fold·IQ0/30은 그 시점 상태이지 최종 결과가 아닙니다.

<a id="guide-results"></a>

## 관측 결과와 해석

실측 시간15:52:20~16:01:53과 평가 조건을 함께 읽습니다. 저장 특징을 다른 검증자가 재계산해 수치가 일치했습니다. IJB-C TAR97.84%@FAR1e-4는 계속 저자 보고이며 LFW 측정으로 바꾸지 않습니다.

<a id="guide-architecture"></a>

## 구현과 핵심 파일

프런트 위치 dashboard/frontend와 서버가 제공하는 dist, 백 엔드 상태 API를 대응합니다. 코드 검사·빌드와 실제 모바일·모션 축소 렌더는 다른 확인입니다. 미확인 상태를 통과로 바꾸지 않습니다.

## 실제 논문과 원고

### LEVEL 3·6,000 쌍과 10fold 임계 값 선택

결과 JSON과 상세 보고서에서 6,000 쌍·fold 분할·5,400 쌍 문턱 선택·FP32/batch4/flip 조건을 확인하세요. 저장 특징으로 재계산한 일치와 원영상을 다시 추론한 실행은 구분합니다. 시험 쌍을 빼서 점수를 높인 실험이 아닙니다.

### LEVEL 3 · 정확도·오거부·표준편차의 서로 다른 의미

5,991 +9 =6,000의 분모와 오거부 9/오수락 0을 결과 집계에서 대조하세요. 요약 반올림 값과 원값을 함께 남기고 표준 편차에 ddof =0 조건을 붙입니다. 99.87과 비교할 때 상대 감소율이나 신뢰구간을 임의 계산해 붙이지 않습니다.

| 조건·자료 | 의미와 확인 방법 |
| --- | --- |
| <a id="layout18-table-4-row-1"></a> 정답과 오 답 | 6,000 쌍 중 정답 5,991·오답 9입니다.<br>동일인을 다른 사람으로 본 오거부 9, 다른 사람을 같은 사람으로 본 오수락 0입니다.<br>두 오류는 다른 위험을 뜻합니다. |
| <a id="layout18-table-4-row-2"></a> 정확도 표시 | 원값 99.85%를 기본 요약에서는 소수 첫째 자리 반올림 99.9%로 표시합니다.<br>저장 원비율과 전체 정밀도 집계는 결과 JSON에서 확인합니다.<br>원값을 바꾸지 않습니다. |
| <a id="layout18-table-4-row-3"></a> fold 표준 편차 | 0.203443%p(ddof =0)는 열 fold 정확도의 퍼짐을 나타냅니다.<br>모집단 모양의 추정이나 95% 신뢰 구간으로 바꾸지 않습니다. |
| <a id="layout18-table-4-row-4"></a> 저자 보고와 차이 | 저자 LFW99.87%와 직접 측정 99.85%의 차이는 −0.02%p입니다.<br>백분율 포인트 차이이며 통계적 동등성이나 우열을 입증하는 검정 결과가 아닙니다. |

### LEVEL 3·IJB-C와 후속 CT는 별도 평가

표의 원 보고/직접 측정/대기 상태를 먼저 확인하세요. IJB-C는 TAR와 FAR를 함께 인용하고,LFW 결과로 대체하지 않습니다. CT를 새로 평가하려면 해당 단계 자료와 환자 그룹 분할을 별도로 갖춰야합니다.

| 조건·자료 | 의미와 확인 방법 |
| --- | --- |
| <a id="layout18-table-5-row-1"></a> IJB-C 원 보고 | TAR97.84%@FAR=1e-4,96.71%@FAR=1e-5는 저자 보고입니다.<br>FAR는 다른 사람을 잘못 받아들이는 비율의 허용 조건이고,TAR는 그 조건에서 같은 사람을 받아들이는 비율입니다. |
| <a id="layout18-table-5-row-2"></a> 현재 상태 | IJB-C는 외부 할당량으로 자료 확보 대기이며 직접 미측정입니다.<br>LFW의 쌍 평가와 IJB-C의 template/media 프로토콜을 같은 시험으로 합치지 않습니다. |
| <a id="layout18-table-5-row-3"></a> CT 전이와 환자분리 | 후속 CT 연구에는 별도 라벨·분할·전처리·학습예산이 필요합니다.환자 매핑이 확인되는 자료의 환자그룹 검증과 매핑 미확인 탐색자료를 섞지 않습니다. |
| <a id="layout18-table-5-row-4"></a> 다른 단계의 의미 | 1 단계 1차 합성 진단 30 항목은 얼굴 정확도나 30회 학습이 아닙니다. 2 단계 30 설정은 계획이며 새 모델 실험 완료가 아닙니다.<br>기존 AdaFace CT 실행은 사용자 중단·보존 상태이고 3 단계/최종 본은 미완료입니다. |


<a id="semantic-preparation-level-3"></a>

### LEVEL 3 · CPU 적재·실패한 정렬·실측의 시점 구분

보고서의 시각·실행 조건·종료 상태를 확인하며 CPU 적재와 GPU 평가를 구분하세요. 실패 쌍을 뺀 결과를 고정 6,000 쌍 성능으로 바꾸지 않습니다. 원 보고 체크섬과 최초 로컬 SHA도 구분해 기록합니다.
