<a id="guide-problem"></a>

## 문제와 주요 기능

얼굴/의료 적응 2초기화 × 동결/마지막 잔 차 블록/전체 3 범위 ×5 시드의 30 설정을 계획합니다. 의료 적응은 추가 자료·계산을 사용하므로 IQ fit 예산 일치와 총 계산 량 일치가 다릅니다.

<a id="guide-flow"></a>

## 입력·처리·출력

BN 통계를 공통 고정하고 NCHW를 유지합니다. 마지막 범위는 backbone.body[-1] 하나와 분류 head이며 동 결 특징은 초기화 별 한 번 추출합니다. fold별 head는 따로 두고 내부 검증만으로 조기 종료·온도 보정·다음 단계 선택을 수행합니다.

<a id="guide-practice"></a>

## 실험과 사용 흐름

소스·자료·분할·설정이 다른 체크포인트 재사용은 차단합니다. NCHW와 공식 Flatten의 제약, 단일 원소 배치 수리, 상태 복원 실패의 원인을 구분합니다. 읽기 전용 API와 실행·학습 기능의 경계를 유지합니다.

<a id="guide-results"></a>

## 관측 결과와 해석

YuNet 정렬 7,631 성공·70 실패·다중 얼굴 511의 관측은 인식 정확도가 아닙니다. 해당 준비는 protocol_unmet이었고 이후 공식 정렬 입력으로 LFW를 평가했습니다. 실패 기록과 성공 평가를 같은 실행으로 합치지 않습니다.

<a id="guide-architecture"></a>

## 구현과 핵심 파일

입력 전처리·strict loading·동결/재동결·BN 복구·장치 이동·체크포인트가 핵심입니다. channels_last는 공식 view 기반 Flatten과 맞지 않아 사용하지 않습니다. 백엔드 판본과 후속 primitive 로더의 범위도 시점별로 나눕니다.

<a id="guide-paper"></a>

## 실제 논문과 원고

원논문·가중치·입력·평가 코드의 대응을 검토합니다. IJB-C 외부 서비스 할당량 대기와 입력 동일성의 미확정 부분이 남습니다. 기술 검사·선정·성능 측정의 증거를 각각 기록합니다.

<a id="guide-limits"></a>

## 조건·실패·미검증 한계

환자 분할·라벨 계보·내부 선택편향·계산 량·입력 동일성이 해석의 제약입니다. LUNA25 영상 CC BY4.0과 주석 CC BY-NC4.0을 보존하며 임의의 재배포 허가를 붙이지 않습니다.

### LEVEL 4 · 정확도·오거부·표준편차의 서로 다른 의미

높은 정답률에서 전체 정확도만 보면 오류 비대칭을 놓칠 수 있습니다. 오수 락 0은 이 고정 시험 쌍에서의 관측이며 모든 사람을 안전하게 구분한다는 보장은 아닙니다.fold 분산과 저자 대비 차이를 같은 불확실성 지표로 합치지 않습니다.

| 조건·자료 | 의미와 확인 방법 |
| --- | --- |
| <a id="layout18-table-4-row-1"></a> 정답과 오 답 | 6,000 쌍 중 정답 5,991·오답 9입니다.<br>동일인을 다른 사람으로 본 오거부 9, 다른 사람을 같은 사람으로 본 오수락 0입니다.<br>두 오류는 다른 위험을 뜻합니다. |
| <a id="layout18-table-4-row-2"></a> 정확도 표시 | 원값 99.85%를 기본 요약에서는 소수 첫째 자리 반올림 99.9%로 표시합니다.<br>저장 원비율과 전체 정밀도 집계는 결과 JSON에서 확인합니다.<br>원값을 바꾸지 않습니다. |
| <a id="layout18-table-4-row-3"></a> fold 표준 편차 | 0.203443%p(ddof =0)는 열 fold 정확도의 퍼짐을 나타냅니다.<br>모집단 모양의 추정이나 95% 신뢰 구간으로 바꾸지 않습니다. |
| <a id="layout18-table-4-row-4"></a> 저자 보고와 차이 | 저자 LFW99.87%와 직접 측정 99.85%의 차이는 −0.02%p입니다.<br>백분율 포인트 차이이며 통계적 동등성이나 우열을 입증하는 검정 결과가 아닙니다. |

### LEVEL 4·IJB-C와 후속 CT는 별도 평가

얼굴 검증과 의료 전이의 평가 경계를 유지합니다. FAR 조건이 다른 TAR는 같은 수치로 직접 비교할 수 없으며 데이터 매핑 수준도 다릅니다. 중단 기록·계획 30 설정·실제 실행을 별도 상태로 다뤄야합니다.

| 조건·자료 | 의미와 확인 방법 |

| <a id="layout18-table-5-row-4"></a> 다른 단계의 의미 | 1 단계 1차 합성 진단 30 항목은 얼굴 정확도나 30회 학습이 아닙니다. 2 단계 30 설정은 계획이며 새 모델 실험 완료가 아닙니다.<br>기존 AdaFace CT 실행은 사용자 중단·보존 상태이고 3 단계/최종 본은 미완료입니다. |


<a id="semantic-preparation-level-4"></a>

### LEVEL 4 · CPU 적재·실패한 정렬·실측의 시점 구분

strict loading은 모델 구조와 파라미터 대응을 확인하지만 입력 동일성·정렬 완전성·정확도를 보장하지 않습니다. 원자 교체 실패의 재시도 보완과 점유 원인 미확정도 분리해야하며 준비 기록을 현재 상태로 덮어 쓰지 않습니다.
