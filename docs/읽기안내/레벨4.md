## 문제와 주요 기능

얼굴/의료 적응2초기화×동결/마지막 잔차블록/전체3범위×5시드의30설정을 계획합니다. 의료 적응은 추가 자료·계산을 사용하므로 IQ fit 예산 일치와 총 계산량 일치가 다릅니다.

<a id="guide-flow"></a>

## 입력·처리·출력

BN 통계를 공통 고정하고 NCHW를 유지합니다. 마지막 범위는 backbone.body[-1] 하나와 분류head이며 동결 특징은 초기화별 한 번 추출합니다. fold별head는 따로 두고 내부 검증만으로 조기 종료·온도 보정·다음 단계 선택을 수행합니다.

<a id="guide-practice"></a>

## 실험과 사용 흐름

소스·자료·분할·설정이 다른 체크포인트 재사용은 차단합니다. NCHW와 공식 Flatten의 제약, 단일 원소 배치 수리, 상태 복원 실패의 원인을 구분합니다. 읽기 전용API와 실행·학습 기능의 경계를 유지합니다.

<a id="guide-results"></a>

## 관측 결과와 해석
