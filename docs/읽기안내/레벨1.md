## 프로젝트 소개

얼굴을 구별하도록 학습한 모델을 먼저 확인하고, 그 특징을 CT 분류에 옮겨 쓸 수 있는지 단계별로 살피는 연구입니다.

얼굴 시험과 CT 연구는 별개입니다.

현재 LFW 얼굴 시험은 측정됐고 IJB-C와 후속 CT 연구는 미완료입니다.

| 적재와 성능 | 모델이 파일을 잘 읽는 것과 사람·질병을 잘 구분하는 것은 다른 확인입니다. |

### LEVEL 1·6,000 쌍과 10fold 임계 값 선택

**쌍은 두 사진이 같은 사람인지 묻는 한 문제**입니다.

임계값은 얼마나 닮으면 같다고 할지 정하는 문턱이며, 시험할 문제를 보며 정하지 않도록 다른 5,400 쌍에서 고릅니다.

입력 횟수와 실제 사람 수를 구분해 결과를 읽으세요.

| 조건·자료 | 의미와 확인 방법 |
| --- | --- |
| <a id="layout18-table-3-row-1"></a> 시험 단위 | TopoFR-R200 Glint360K를 공식 MS1MV2 제공 정렬 LFW의 6,000 쌍으로 평가했습니다.<br>영상 입력 12,000회는 같은 사진의 재사용을 포함하며 고유 사진이나 인물 12,000개를 뜻하지 않습니다. |
| <a id="layout18-table-3-row-2"></a> 10fold | 평가 쌍을 열 묶음으로 나눕니다.<br>매번 시험할 묶음과 분리된 5,400 쌍에서 같은 사람으로 판단할 거리 임계값을 고르고, 남긴 쌍을 평가해 6,000 쌍을 한 번씩 시험합니다. |
| <a id="layout18-table-3-row-3"></a> 실제 추론 조건 | 2026-11-03 한국 시각15:52:20~16:01:53에 FP32·batch4·원본/좌우 반전 특징 합으로 GPU 평가를 완료했습니다.<br>FP32는 수치 정밀도,batch4는 한 번에 처리하는 묶음, 반전은 같은 사진을 좌우로 바꿔 얻은 특징을 함께 쓰는 조건입니다. |
| <a id="layout18-table-3-row-4"></a> 별도 재계산 | 재학습·실패 쌍 삭제·결과에 맞춘 전처리 변경 없이 저장 특징에서 다른 검증자가 NumPy 거리·임계값·10fold를 재계산해 일치를 확인했습니다. |

### LEVEL 1 · 정확도·오거부·표준편차의 서로 다른 의미

같은 사람을 놓친 오류와 다른 사람을 받아들인 오류를 따로 보세요.**99.9%는 반올림 요약이고 원값은 99.85%**입니다.열 묶음의 점수가 얼마나 달랐는지 보는 표준편차는 앞으로 나올 점수의 보장 구간이 아닙니다.

| 조건·자료 | 의미와 확인 방법 |
| --- | --- |

<a id="semantic-ijb-level-1"></a>

### LEVEL 1·IJB-C와 후속 CT는 별도 평가

얼굴 시험 하나를 끝냈다고 CT나 다른 얼굴 시험까지 끝난 것은 아닙니다.

IJB-C의 높은 숫자는 저자 보고이고 여기서 직접 얻은 값은 아닙니다.

중단한 CT 작업을 현재 진행 중이나 완료로 바꾸어 읽지 마세요.

| 조건·자료 | 의미와 확인 방법 |
| --- | --- |
| <a id="layout18-table-5-row-1"></a> IJB-C 원 보고 | TAR97.84%@FAR=1e-4,96.71%@FAR=1e-5는 저자 보고입니다.<br>FAR는 다른 사람을 잘못 받아들이는 비율의 허용 조건이고,TAR는 그 조건에서 같은 사람을 받아들이는 비율입니다. |
| <a id="layout18-table-5-row-2"></a> 현재 상태 | IJB-C는 외부 할당량으로 자료 확보 대기이며 직접 미측정입니다.<br>LFW의 쌍 평가와 IJB-C의 template/media 프로토콜을 같은 시험으로 합치지 않습니다. |
| <a id="layout18-table-5-row-3"></a> CT 전이와 환자분리 | 후속 CT 연구에는 별도 라벨·분할·전처리·학습예산이 필요합니다.환자 매핑이 확인되는 자료의 환자그룹 검증과 매핑 미확인 탐색자료를 섞지 않습니다. |
| <a id="layout18-table-5-row-4"></a> 다른 단계의 의미 | 1 단계 1차 합성 진단 30 항목은 얼굴 정확도나 30회 학습이 아닙니다. 2 단계 30 설정은 계획이며 새 모델 실험 완료가 아닙니다.<br>기존 AdaFace CT 실행은 사용자 중단·보존 상태이고 3 단계/최종 본은 미완료입니다. |


<a id="semantic-preparation-level-1"></a>

### LEVEL 1 · CPU 적재·실패한 정렬·실측의 시점 구분

모델파일을 읽은 것,얼굴위치를 찾은 것,같은사람인지 맞힌 것은 다른 확인입니다.준비 당시의 **미측정** 기록과 이후 실측 기록을 시점대로 읽으세요.

정렬에서 70개가 실패한 사실은 나중 평가가 끝나도 없어지지 않습니다.
