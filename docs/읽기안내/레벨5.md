## 프로젝트 소개

검토 축은 가중치·입력 동일성, 얼굴 프로토콜, 의료 라벨·분할·선택, 실행 예산과 중단 계보입니다.

LFW 실측의 독립 재계산은 확인됐지만 IJB-C·의료 성능·모든 입력 바이트의 저자 당시 동일성을 대체하지 않습니다.

### LEVEL 5·6,000 쌍과 10fold 임계 값 선택

고정 6,000 쌍·각 fold 외 5,400 쌍 임계값 추정·FP32/batch4/flip 합·저장 특징 독립 재계산을 분리해 명세화합니다.

입력 12,000회는 독립 표본 수가 아니며 저자 bin/디코더 동일성까지 확인된 재현이라고 확대하지 않습니다.

### LEVEL 5 · 정확도·오거부·표준편차의 서로 다른 의미

정답/오거부/오수락 분모·정확도 원값·표시정밀도·population fold std(ddof0)를 유지합니다.

저자 대비 −0.02%p는 입력 동일성 미확인 조건의 단순 차이이며 등가성 검정이나 유의성 결과로 해석할 수 없습니다.

| 조건·자료 | 의미와 확인 방법 |
| --- | --- |
| <a id="layout18-table-4-row-1"></a> 정답과 오 답 | 6,000 쌍 중 정답 5,991·오답 9입니다.<br>동일인을 다른 사람으로 본 오거부 9, 다른 사람을 같은 사람으로 본 오수락 0입니다.<br>두 오류는 다른 위험을 뜻합니다. |
| <a id="layout18-table-4-row-2"></a> 정확도 표시 | 원값 99.85%를 기본 요약에서는 소수 첫째 자리 반올림 99.9%로 표시합니다.<br>저장 원비율과 전체 정밀도 집계는 결과 JSON에서 확인합니다.<br>원값을 바꾸지 않습니다. |
| <a id="layout18-table-4-row-3"></a> fold 표준 편차 | 0.203443%p(ddof =0)는 열 fold 정확도의 퍼짐을 나타냅니다.<br>모집단 모양의 추정이나 95% 신뢰 구간으로 바꾸지 않습니다. |
| <a id="layout18-table-4-row-4"></a> 저자 보고와 차이 | 저자 LFW99.87%와 직접 측정 99.85%의 차이는 −0.02%p입니다.<br>백분율 포인트 차이이며 통계적 동등성이나 우열을 입증하는 검정 결과가 아닙니다. |

임상 성능·세계 절대 최고·전체 단계 완료 주장을 하지 않으며 저자/상용/비공개 모델 전체를 평가한 선정으로 확대하지 않습니다.

| 조건·자료 | 의미와 확인 방법 |

| <a id="layout18-table-5-row-2"></a> 현재 상태 | IJB-C는 외부 할당량으로 자료 확보 대기이며 직접 미측정입니다.<br>LFW의 쌍 평가와 IJB-C의 template/media 프로토콜을 같은 시험으로 합치지 않습니다. |

### LEVEL 5 · CPU 적재·실패한 정렬·실측의 시점 구분

12:08실패/12:14:53CPU 통과/이전 YuNet protocol_unmet/공식 입력 획득/15:52GPU 실 측을 시점별 증거로 유지합니다.
