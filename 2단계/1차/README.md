# 🫁 2단계 · 실제 CT 전이 분류 1차

원래 얼굴 사전학습 모델의 LUNA25 이진 환자별 평가와, 별도 LUNA25 보조 학습 뒤 IQ 정상·양성·악성 탐색을 구현합니다. 현재 파일은 실행 소스이며 임상 성능 보고가 아닙니다.

| 분석 | 자료 | 분할 | 해석 |
|---|---|---|---|
| A | LUNA25 공식 이진 주석 | 환자 그룹 7fold·내부 검증 | 원래 얼굴 고정 특징의 결절 주석 시점별 이진 평가 |
| B | IQ 기존 3분류 | 디코딩 화소 정확 중복 그룹 7fold·내부 검증 | 환자 매핑 미확인 탐색 분석 |
| 보조 적응 | 전체 LUNA25 | 독립 평가 없음·고정 epoch | IQ용 초기화 한 번 생성 |

LUNA25에는 정상 클래스가 없습니다. IQ 정상과 LUNA25 결절 ROI를 하나의 3분류 테이블로 합치지 않습니다. LUNA25 6,163개는 주석·검사 시점 수이며 고유 결절·환자 수와 구분합니다. IQ 파일명은 환자 키로 사용하지 않습니다.

보유 IQ 1,097개는 [저자 GitHub 고정 배포](https://github.com/hamdalla93/The-IQ-OTHNCCD-lung-cancer-dataset/tree/edcdd5a73e8e92377d2a47e69c0b9a551e1c5ce3)의 JPG 1,097개와 상대 경로·길이·Git blob SHA-1 전부가 일치했습니다. Mendeley ZIP 전체와 환자 매핑은 검증하지 않았으며 설명의 1,190영상·110명을 이 보유자료의 확정값으로 사용하지 않습니다.

## 실행

아래 명령의 현재 위치는 `2단계/1차`입니다. 모든 원본은 읽기만 하며 파생 캐시는 `2단계/data`, 가중치는 `2단계/models`, 개별 결과와 운영 기록은 `2단계/work/private`에 저장합니다. 장기 학습은 독립 검증 뒤 실행하며 이번 공개 묶음은 학습 전 준비 자료를 담습니다.

```powershell
& '../../1단계/work/venv/Scripts/python.exe' -B -X utf8 -m unittest discover -s tests -v
& '../../1단계/work/venv/Scripts/python.exe' -B -X utf8 tools/run_stage2.py prepare
& '../../1단계/work/venv/Scripts/python.exe' -B -X utf8 tools/run_stage2.py benchmark
& '../../1단계/work/venv/Scripts/python.exe' -B -X utf8 tools/run_stage2.py run
```

`benchmark`는 소수의 실제 IQ 영상으로 CUDA 학습·추론 시간을 측정하고 비공개 실행 예산을 고정합니다. `run`은 그 예산과 현재 소스 해시가 같을 때만 시작합니다. 같은 명령은 체크포인트로 재개하며 다른 소스·자료·분할·설정의 재사용은 차단합니다.

전체 7일 상한은 최초 `run`의 UTC 종료 시각으로 저장하며 재개로 연장하지 않습니다. 특징 추출·학습·평가의 배치 경계에서 확인하고, 중단한 특징과 optimizer·RNG·배치 위치를 보존합니다.

단일 원소 배치 수리 후 재측정에서는 공통 배치 16을 선택했습니다. 학습 가능한 backbone은 native BF16 AMP를 명시하며 동결 head·특징 추출·평가는 FP32를 유지합니다. 첫 실제 실행은 첫 LUNA25 head에서 실패해 완료 fold가 0개였고, 이 문장의 준비 기록 시점은 재시작 전이며, 수리 후 학습은 아래 07:12 기록과 같이 재시작했습니다. [실측 준비·검사 기록](docs/구현_검증_기록.md)은 학습 결과와 구분합니다.

## 비교와 후속 단계

얼굴/의료 적응 2초기화 × 동결/마지막 잔차 블록/전체 3범위 × 시드 5개로 30설정을 만듭니다. 마지막 범위는 `backbone.body[-1]` 하나와 분류 head입니다. BN 통계는 공통 고정하고 NCHW를 유지합니다. IQ는 같은 배치 크기·최대 epoch·시드별 head 초기값을 공유합니다. 동결 특징은 초기화별 한 번 추출하며 fold별 head는 분리합니다. 의료 적응에는 추가 자료와 계산이 사용되므로 IQ fit 예산 일치와 전체 계산량 일치를 구분해야 합니다.

조기 종료는 내부 검증 macro-F1, 온도 보정은 같은 내부 검증 logits만 사용합니다. 3단계 인계는 외부 시험 점수 대신 각 fold의 내부 검증 점수로 선택합니다. 이 선택에도 내부 검증 재사용에 따른 선택 편향 가능성이 있어 별도 외부 임상 확인을 대신하지 않습니다.

LUNA25 신뢰구간은 환자 단위 cluster bootstrap으로 계산합니다. IQ의 환자 신뢰구간은 비워 두며, 다섯 시드의 분산은 학습 난수에 따른 변동만 나타냅니다. 이를 환자 표본 또는 임상 불확실성의 대체값으로 사용하지 않습니다.

각 설정의 7개 fold가 실제 완료된 뒤에만 `reports/설정_XX.md`가 생성됩니다. raw CT·환자 키·특징·가중치·개별 확률·비공개 로그는 공개 대상에서 제외합니다.

## 2026-11-03 07:12 재시작 확인

수리 뒤 독립 검증에서 36개 검사를 모두 통과했고, 마지막 한 영상 배치·읽기 전용 memmap·중단 후 재개 경로를 추가 확인했습니다. 이전 33개 검사 통과와 06:48 첫 실제 실행 실패는 그대로 보존합니다. 07:01 새 자원 측정에서 공통 배치 16을 선택한 소스로 07:12:34 한국 시각에 실제 학습을 재시작했습니다.

07:12 확인 시점에는 특징 계산 중이었고 LUNA25 이진 평가의 완료 외부 fold는 0개, IQ 완료 설정은 0/30이었습니다. 이는 재시작 상태 관측이며 임상 분류 결과가 아닙니다. 이번 묶음은 코드·자료 준비·자원 실측의 공개이며 30설정 결과 보고서나 결과 공개 커밋 횟수에 포함하지 않습니다. 이후 실제 학습 결과는 별도 검증해 공개합니다.
