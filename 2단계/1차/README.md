### LEVEL 1 · 목적과 대상

**이 차수의 목적과 실제 구성**

원래 얼굴 사전학습 모델의 LUNA25 이진 환자별 평가와, 별도 LUNA25 보조 학습 뒤 IQ 정상·양성·악성 탐색을 구현합니다. 현재 파일은 실행 소스이며 임상 성능 보고가 아닙니다.

| 분석 | 자료 | 분할 | 해석 |
| --- | --- | --- | --- |
| A | LUNA25 공식 이진 주석 | 환자 그룹 7fold·내부 검증 | 원래 얼굴 고정 특징의 결절 주석 시점별 이진 평가 |
| B | IQ 기존 3 분류 | 디코딩 화소 정확 중복 그룹 7fold·내부 검증 | 환자 매핑 미확인 탐색 분석 |
| 보조 적응 | 전체 LUNA25 | 독립 평가 없음·고정 epoch | IQ용 초기화 한 번 생성 |

LUNA25에는 정상 클래스가 없습니다. IQ 정상과 LUNA25 결절 ROI를 하나의 3 분류 테이블로 합치지 않습니다. LUNA25 6,163개는 주석·검사 시점 수이며 고 유 결절·환자 수와 구분합니다. IQ 파일명은 환자 키로 사용하지 않습니다.

보유 IQ 1,097개는 [저자 GitHub 고정 배포](https://github.com/hamdalla93/The-IQ-OTHNCCD-lung-cancer-dataset/tree/edcdd5a73e8e92377d2a47e69c0b9a551e1c5ce3)의 JPG 1,097개와 상대 경로·길이·Git blob SHA-1 전부가 일치했습니다.

Mendeley ZIP 전체와 환자 매핑은 검증하지 않았으며 설명의 1,190 영상·110명을 이 보유 자료의 확정 값으로 사용하지 않습니다.

얼굴을 구별하도록 학습한 모델을 먼저 확인하고, 그 특징을 CT 분류에 옮겨 쓸 수 있는지 단계별로 살피는 연구입니다. 얼굴 시험과 CT 연구는 별개입니다. **현재 LFW 얼굴 시험은 측정됐고 IJB-C와 후속 CT 연구는 미완료**입니다.

얼굴 모델 원래 특징의 LUNA25 평가와 의료 적응 후 IQ 탐색을 분리합니다. 초기 실제 실패·수리·07:12 재시작 이력은 그대로 남깁니다.

얼굴에서 익힌 무늬가 CT 분류에도 도움이 되는지 묻습니다. 모델이 파일을 잘 읽는 것과 사람·질병을 잘 구분하는 것은 다른 확인입니다. 자료에 정상 사진이 없는 경우 억지로 정상·양성·악성 세 종류로 합치지 않습니다.

### LEVEL 1 · 입력과 실행 조건

원래 얼굴 사전학습 모델의 LUNA25 이진 환자별 평가와, 별도 LUNA25 보조 학습 뒤 IQ 정상·양성·악성 탐색을 구현합니다. 현재 파일은 실행 소스이며 임상 성능 보고가 아닙니다.

얼굴/의료 적응 2초기화 × 동결/마지막 잔 차 블록/전체 3 범위 × 시드 5개로 30 설정을 만듭니다. 마지막 범위는 `backbone.body[-1]` 하나와 분류 head입니다. BN 통계는 공통 고정하고 NCHW를 유지합니다.

IQ는 같은 배치 크기·최대 epoch·시드별 head 초기값을 공유합니다. 동결 특징은 초기화 별 한 번 추출하며 fold별 head는 분리합니다.

의료 적응에는 추가 자료와 계산이 사용되므로 IQ fit 예산 일치와 전체 계산량 일치를 구분해야 합니다.

조기 종료는 내부 검증 macro-F1, 온도 보정은 같은 내부 검증 logits만 사용합니다. 3 단계 인계는 외부 시험 점수 대신 각 fold의 내부 검증 점수로 선택합니다. 이 선택에도 내부 검증 재사용에 따른 선택 편향 가능성이 있어 별도 외부 임상 확인을 대신하지 않습니다.

LUNA25 신뢰구간은 환자 단위 cluster bootstrap으로 계산합니다. IQ의 환자 신뢰구간은 비워 두며, 다섯 시드의 분산은 학습 난수에 따른 변동만 나타냅니다. 이를 환자 표본 또는 임상 불확실성의 대체 값으로 사용하지 않습니다.

각 설정의 7개 fold가 실제 완료된 뒤에만 `reports/설정_XX.md`가 생성됩니다. raw CT·환자 키·특징·가중치·개별 확률·비공개 로그는 공개 대상에서 제외합니다.

영상은 CC BY 4.0, 주석은 CC BY-NC 4.0입니다. 원본 라이선스와 비상업적 주석 조건을 보존하며 본 소스에 임의의 원본 데이터 재배포 허가를 붙이지 않습니다.

가중치를 확인하고 사진이 모델에 들어가는 형태를 검사한 뒤 얼굴 평가를 합니다. CT 단계는 별도 자료·라벨·분할을 준비합니다. 한 단계의 성공을 다음 단계가 끝난 것으로 표시하지 않습니다.

### LEVEL 1 · 처리 절차

아래 명령의 현재 위치는 `2단계/1차`입니다. 모든 원본은 읽기만 하며 파생 캐시는 `2단계/data`, 가중치는 `2단계/models`, 개별 결과와 운영 기록은 `2단계/work/private`에 저장합니다. 장기 학습은 독립 검증 뒤 실행하며 이번 공개 묶음은 학습 전 준비 자료를 담습니다.


`benchmark`는 소수의 실제 IQ 영상으로 CUDA 학습·추론 시간을 측정하고 비공개 실행 예산을 고정합니다. `run`은 그 예산과 현재 소스 해시가 같을 때만 시작합니다. 같은 명령은 체크포인트로 재개하며 다른 소스·자료·분할·설정의 재사용은 차단합니다.

전체 7일 상한은 최초 `run`의 UTC 종료 시각으로 저장하며 재개로 연장하지 않습니다. 특징 추출·학습·평가의 배치 경계에서 확인하고, 중단한 특징과 optimizer·RNG·배치 위치를 보존합니다.

단일 원소 배치 수리 후 재측정에서는 공통 배치 16을 선택했습니다. 학습 가능한 backbone은 native BF16 AMP를 명시하며 동결 head·특징 추출·평가는 FP32를 유지합니다.

첫 실제 실행은 첫 LUNA25 head에서 실패해 완료 fold가 0개였습니다. 이 문장의 준비 기록 시점은 재시작 전입니다. 수리 후 학습은 아래 07:12 기록과 같이 재시작했습니다. [실측 준비·검사 기록](docs/구현_검증_기록.md)은 학습 결과와 구분합니다.

처음에는 실제 LFW 결과와 당시 준비 기록을 나누어 읽습니다. 화면의 로그와 상태는 읽기 전용입니다. 버튼이 있다고 학습을 새로 시작하는 앱은 아닙니다.

### LEVEL 1 · 결과를 확인하는 방법

수리 뒤 독립 검증에서 36개 검사를 모두 통과했고, 마지막 한 영상 배치·읽기 전용 memmap·중단 후 재개 경로를 추가 확인했습니다. 이전 33개 검사 통과와 06:48 첫 실제 실행 실패는 그대로 보존합니다.

07:01 새 자원 측정에서 공통 배치 16을 선택한 소스로 07:12:34 한국 시각에 실제 학습을 재시작했습니다.

07:12 확인 시점에는 특징 계산 중이었고 LUNA25 이진 평가의 완료 외부 fold는 0개, IQ 완료 설정은 0/30이었습니다. 이는 재시작 상태 관측이며 임상 분류 결과가 아닙니다.

이번 묶음은 코드·자료 준비·자원 실 측의 공개이며 30 설정 결과 보고서나 결과 공개 커밋 횟수에 포함하지 않습니다. 이후 실제 학습 결과는 별도 검증해 공개합니다.

LFW6,000 쌍에서 5,991 쌍을 맞추고 9 쌍을 틀려 원값 99.85%를 얻었습니다. 요약 99.9%는 반올림 표시입니다. 사진 입력 12,000회는 같은 사진이 다시 들어간 횟수를 포함하며 12,000명의 사람을 뜻하지 않습니다.

### LEVEL 1 · 주의할 범위

LUNA25에는 정상 클래스가 없고 IQ 환자 매핑은 미확인입니다. IQ 시드 분산은 환자 불확실성이 아닙니다. LUNA25 영상 CC BY4.0·주석 CC BY-NC4.0 조건을 보존하며 의료 원자료·특징·가중치·개별 확률은 공개하지 않습니다.

기존 AdaFace CT 실행은 사용자가 중단했고 자료를 보존했습니다. IJB-C는 아직 측정하지 않았습니다. 얼굴에서 높은 정확도가 나와도 CT 임상 성능이 확인된 것은 아닙니다.

### LEVEL 2 · 목적과 대상

IQ는 같은 배치 크기·최대 epoch·시드별 head 초기값을 공유합니다. 동결 특징은 초기화 별 한 번 추출하며 fold별 head는 분리합니다.

의료 적응에는 추가 자료와 계산이 사용되므로 IQ fit 예산 일치와 전체 계산량 일치를 구분해야 합니다.

조기 종료는 내부 검증 macro-F1, 온도 보정은 같은 내부 검증 logits만 사용합니다. 3 단계 인계는 외부 시험 점수 대신 각 fold의 내부 검증 점수로 선택합니다. 이 선택에도 내부 검증 재사용에 따른 선택 편향 가능성이 있어 별도 외부 임상 확인을 대신하지 않습니다.

LUNA25 신뢰구간은 환자 단위 cluster bootstrap으로 계산합니다. IQ의 환자 신뢰구간은 비워 두며, 다섯 시드의 분산은 학습 난수에 따른 변동만 나타냅니다. 이를 환자 표본 또는 임상 불확실성의 대체 값으로 사용하지 않습니다.

### LEVEL 2 · 처리 절차

아래 명령의 현재 위치는 `2단계/1차`입니다. 모든 원본은 읽기만 하며 파생 캐시는 `2단계/data`, 가중치는 `2단계/models`, 개별 결과와 운영 기록은 `2단계/work/private`에 저장합니다. 장기 학습은 독립 검증 뒤 실행하며 이번 공개 묶음은 학습 전 준비 자료를 담습니다.


`benchmark`는 소수의 실제 IQ 영상으로 CUDA 학습·추론 시간을 측정하고 비공개 실행 예산을 고정합니다. `run`은 그 예산과 현재 소스 해시가 같을 때만 시작합니다. 같은 명령은 체크포인트로 재개하며 다른 소스·자료·분할·설정의 재사용은 차단합니다.

전체 7일 상한은 최초 `run`의 UTC 종료 시각으로 저장하며 재개로 연장하지 않습니다. 특징 추출·학습·평가의 배치 경계에서 확인하고, 중단한 특징과 optimizer·RNG·배치 위치를 보존합니다.

단일 원소 배치 수리 후 재측정에서는 공통 배치 16을 선택했습니다. 학습 가능한 backbone은 native BF16 AMP를 명시하며 동결 head·특징 추출·평가는 FP32를 유지합니다.

첫 실제 실행은 첫 LUNA25 head에서 실패해 완료 fold가 0개였습니다. 이 문장의 준비 기록 시점은 재시작 전입니다. 수리 후 학습은 아래 07:12 기록과 같이 재시작했습니다. [실측 준비·검사 기록](docs/구현_검증_기록.md)은 학습 결과와 구분합니다.

공식 입력·가중치 수신, strict 적재, 합성 검사, 실제 얼굴 평가의 순서를 구분합니다. CT의 benchmark는 자원 측정이고 run은 고정한 예산·소스가 맞을 때 학습을 시작합니다. 준비 검사 통과가 최종 성능은 아닙니다.

### LEVEL 2 · 결과를 확인하는 방법

수리 뒤 독립 검증에서 36개 검사를 모두 통과했고, 마지막 한 영상 배치·읽기 전용 memmap·중단 후 재개 경로를 추가 확인했습니다. 이전 33개 검사 통과와 06:48 첫 실제 실행 실패는 그대로 보존합니다.

07:01 새 자원 측정에서 공통 배치 16을 선택한 소스로 07:12:34 한국 시각에 실제 학습을 재시작했습니다.

07:12 확인 시점에는 특징 계산 중이었고 LUNA25 이진 평가의 완료 외부 fold는 0개, IQ 완료 설정은 0/30이었습니다. 이는 재시작 상태 관측이며 임상 분류 결과가 아닙니다.

이번 묶음은 코드·자료 준비·자원 실 측의 공개이며 30 설정 결과 보고서나 결과 공개 커밋 횟수에 포함하지 않습니다. 이후 실제 학습 결과는 별도 검증해 공개합니다.

10fold 평균 99.85%는 저자 보고 99.87%보다 −0.02%p입니다. 같은 사람을 다르다고 한 9건, 다른 사람을 같다고 한 0건입니다. fold 표준 편차 0.203443%p는 신뢰구간과 다릅니다.

분류 A는 LUNA25 공식 이 진 주석과 환자 그룹 7fold, B는 IQ의 정확화 소 중 복 그룹 7fold입니다. IQ 환자 매핑은 미확인입니다. 주석·검사 시점 수와 고유 환자·결 절 수를 구분해야 합니다.

### LEVEL 3 · 입력과 실행 조건

원래 얼굴 사전학습 모델의 LUNA25 이진 환자별 평가와, 별도 LUNA25 보조 학습 뒤 IQ 정상·양성·악성 탐색을 구현합니다. 현재 파일은 실행 소스이며 임상 성능 보고가 아닙니다.

| 분석 | 자료 | 분할 | 해석 |
| --- | --- | --- | --- |
| A | LUNA25 공식 이진 주석 | 환자 그룹 7fold·내부 검증 | 원래 얼굴 고정 특징의 결절 주석 시점별 이진 평가 |
| B | IQ 기존 3 분류 | 디코딩 화소 정확 중복 그룹 7fold·내부 검증 | 환자 매핑 미확인 탐색 분석 |
| 보조 적응 | 전체 LUNA25 | 독립 평가 없음·고정 epoch | IQ용 초기화 한 번 생성 |

LUNA25에는 정상 클래스가 없습니다. IQ 정상과 LUNA25 결절 ROI를 하나의 3 분류 테이블로 합치지 않습니다. LUNA25 6,163개는 주석·검사 시점 수이며 고 유 결절·환자 수와 구분합니다. IQ 파일명은 환자 키로 사용하지 않습니다.

보유 IQ 1,097개는 [저자 GitHub 고정 배포](https://github.com/hamdalla93/The-IQ-OTHNCCD-lung-cancer-dataset/tree/edcdd5a73e8e92377d2a47e69c0b9a551e1c5ce3)의 JPG 1,097개와 상대 경로·길이·Git blob SHA-1 전부가 일치했습니다.

Mendeley ZIP 전체와 환자 매핑은 검증하지 않았으며 설명의 1,190 영상·110명을 이 보유 자료의 확정 값으로 사용하지 않습니다.

얼굴/의료 적응 2초기화 × 동결/마지막 잔 차 블록/전체 3 범위 × 시드 5개로 30 설정을 만듭니다. 마지막 범위는 `backbone.body[-1]` 하나와 분류 head입니다. BN 통계는 공통 고정하고 NCHW를 유지합니다.

IQ는 같은 배치 크기·최대 epoch·시드별 head 초기값을 공유합니다. 동결 특징은 초기화 별 한 번 추출하며 fold별 head는 분리합니다.

의료 적응에는 추가 자료와 계산이 사용되므로 IQ fit 예산 일치와 전체 계산량 일치를 구분해야 합니다.

조기 종료는 내부 검증 macro-F1, 온도 보정은 같은 내부 검증 logits만 사용합니다. 3 단계 인계는 외부 시험 점수 대신 각 fold의 내부 검증 점수로 선택합니다. 이 선택에도 내부 검증 재사용에 따른 선택 편향 가능성이 있어 별도 외부 임상 확인을 대신하지 않습니다.

LUNA25 신뢰구간은 환자 단위 cluster bootstrap으로 계산합니다. IQ의 환자 신뢰구간은 비워 두며, 다섯 시드의 분산은 학습 난수에 따른 변동만 나타냅니다. 이를 환자 표본 또는 임상 불확실성의 대체 값으로 사용하지 않습니다.

각 설정의 7개 fold가 실제 완료된 뒤에만 `reports/설정_XX.md`가 생성됩니다. raw CT·환자 키·특징·가중치·개별 확률·비공개 로그는 공개 대상에서 제외합니다.

### LEVEL 3 · 처리 절차

아래 명령의 현재 위치는 `2단계/1차`입니다. 모든 원본은 읽기만 하며 파생 캐시는 `2단계/data`, 가중치는 `2단계/models`, 개별 결과와 운영 기록은 `2단계/work/private`에 저장합니다. 장기 학습은 독립 검증 뒤 실행하며 이번 공개 묶음은 학습 전 준비 자료를 담습니다.


`benchmark`는 소수의 실제 IQ 영상으로 CUDA 학습·추론 시간을 측정하고 비공개 실행 예산을 고정합니다. `run`은 그 예산과 현재 소스 해시가 같을 때만 시작합니다. 같은 명령은 체크포인트로 재개하며 다른 소스·자료·분할·설정의 재사용은 차단합니다.

전체 7일 상한은 최초 `run`의 UTC 종료 시각으로 저장하며 재개로 연장하지 않습니다. 특징 추출·학습·평가의 배치 경계에서 확인하고, 중단한 특징과 optimizer·RNG·배치 위치를 보존합니다.

단일 원소 배치 수리 후 재측정에서는 공통 배치 16을 선택했습니다. 학습 가능한 backbone은 native BF16 AMP를 명시하며 동결 head·특징 추출·평가는 FP32를 유지합니다.

첫 실제 실행은 첫 LUNA25 head에서 실패해 완료 fold가 0개였습니다. 이 문장의 준비 기록 시점은 재시작 전입니다. 수리 후 학습은 아래 07:12 기록과 같이 재시작했습니다. [실측 준비·검사 기록](docs/구현_검증_기록.md)은 학습 결과와 구분합니다.

7일 상한은 최초 run의 종료 시각으로 고정하며 재개로 연장하지 않습니다. 중단한 특징·optimizer·RNG·배치 위치를 보존합니다. 07:12 재시작 관측의 완료 0fold·IQ0/30은 그 시점 상태이지 최종 결과가 아닙니다.

얼굴/의료 적응 2초기화 × 동결/마지막 잔 차 블록/전체 3 범위 × 시드 5개로 30 설정을 만듭니다. 마지막 범위는 `backbone.body[-1]` 하나와 분류 head입니다. BN 통계는 공통 고정하고 NCHW를 유지합니다.

IQ는 같은 배치 크기·최대 epoch·시드별 head 초기값을 공유합니다. 동결 특징은 초기화 별 한 번 추출하며 fold별 head는 분리합니다.

의료 적응에는 추가 자료와 계산이 사용되므로 IQ fit 예산 일치와 전체 계산량 일치를 구분해야 합니다.

조기 종료는 내부 검증 macro-F1, 온도 보정은 같은 내부 검증 logits만 사용합니다. 3 단계 인계는 외부 시험 점수 대신 각 fold의 내부 검증 점수로 선택합니다. 이 선택에도 내부 검증 재사용에 따른 선택 편향 가능성이 있어 별도 외부 임상 확인을 대신하지 않습니다.
