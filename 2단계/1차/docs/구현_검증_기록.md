# 구현·자료 준비·자원 실측 기록

확인일: 2026-11-03. 실제 자료 준비와 첫 실패 실행 뒤 수리·재측정에 관한 구현자 직접 검사 기록이다. 독립 검증 영수증이나 임상 성능 결과가 아니다.

## 실제 자료 준비

공식 LUNA25 두 블록 조각과 주석 CSV의 고정 MD5를 재대조한 뒤 분할 ZIP을 가상 연결하여 읽었다. 6,163개 주석 시점·3,762개 고유 결절·2,120명의 입력 캐시를 생성했다. 이진 주석은 양성 5,608개·악성 555개이며 정상 라벨을 만들지 않았다. 원래 체적은 복사·수정하지 않았다.

IQ는 기존 1,097개 영상(정상 416·양성 120·악성 561)을 읽어 1,054개 정확 화소 중복 그룹으로 묶었다. 환자 키는 미확인이며 파일명으로 추정하지 않았다. 환자별 이진 분석과 IQ 3분류 탐색은 분리한다.

추가 출처 대조에서 저자 GitHub의 commit `edcdd5a73e8e92377d2a47e69c0b9a551e1c5ce3`, tree `8391fd75b28a929e491870b8413c63344b1de5a8`의 JPG 1,097개와 보유자료의 상대 경로·길이·Git blob SHA-1이 모두 일치했다. 누락·추가·불일치 0이다. [고정 원본 tree](https://github.com/hamdalla93/The-IQ-OTHNCCD-lung-cancer-dataset/tree/edcdd5a73e8e92377d2a47e69c0b9a551e1c5ce3)와의 동일성에 한정하며, Mendeley ZIP 전체와 환자 매핑은 미검증이다. 설명의 1,190영상·110명을 보유자료의 확정값으로 사용하지 않는다.

양쪽 캐시 전체를 확인해 float32·유한값·[-1,1] 범위를 검증했다. 각 외부 fold의 학습·내부 검증·시험은 그룹이 겹치지 않고 모든 클래스를 포함한다. LUNA25 캐시는 1×112×112이고 모델에 넣을 때 세 채널로 복제한다. IQ 캐시는 3×112×112이다.

물리 간격 수식·최적 체크포인트 복원·전체 종료 시각·FP16 초기 스케일·실패 전 관측 보존의 이전 실패와 제어 결함 주입 기록은 비공개 보존했다. 나중 통과로 이전 기록을 바꾸지 않았다. 타입 검사·린트 전용 도구는 프로젝트 명세에 없어 별도로 실행하지 않았다.

## 정밀도 진단

RTX 4090과 PyTorch 2.11.0+cu128에서 native BF16 지원을 직접 확인했다. 동일 초기 가중치·시드·실제 IQ 배치의 세 학습 범위에 FP32·BF16·FP16 스케일 1·FP16 스케일 65,536을 대조했다. 파라미터 갱신 없는 진단에서 full의 FP16 스케일 65,536만 비유한 경사를 보였다. 다른 조건의 손실·경사는 유한했다.

BF16 평가 logits의 FP32 대비 최대 절대 차이는 0.0157924, softmax 최대 절대 차이는 0.0027481이었다. 네 영상의 argmax 일치는 1.0이었으나 임상 정확도나 정밀도 간 학습 성능 동등성의 근거로 사용하지 않는다. 학습 모드에는 Dropout과 정밀도별 연산 경로 차이가 있다. 고정 모델의 특징 추출·동결 head·평가는 FP32로 수행하며 마지막 블록·전체·보조 적응 학습에 명시한 BF16 AMP를 사용한다.

## 고정 실행 예산과 후속 작업

IQ는 최대 20epoch·인내 5epoch·배치 16·head 학습률 0.001·backbone 학습률 0.00001·AdamW·가중치 감쇠 0.01·warmup 2epoch를 사용한다. 보조 적응은 전체 LUNA25를 고정 2epoch 학습하며 독립 평가를 만들지 않는다. LUNA25 원래 얼굴 고정 특징의 이진 head는 최대 40epoch다.

run05 실측과 실제 fold별 단계 수에 1.5 계수를 적용한 IQ backbone 학습 구간 추정은 약 5.26시간, 보조 적응 추정은 약 2.08분이다. 이전 run04의 7.43시간·2.72분 예산은 실패 실행 보관본에 남겼다. 특징 일회 추출·동결 head·체크포인트 I/O·초기 적재·경합 변화는 별도로 고려해야 한다. 조기 종료와 장치 상태에 따라 실제 시간은 달라진다. 최초 `run`에 고정하는 UTC 7일 상한은 재개로 연장하지 않는다.

소스·자료·분할·예산 해시가 맞아야 실행·재개한다. 첫 실행의 실제 완료 fold는 0개였다. 이 준비 기록 이후 수리 뒤 학습을 아래 07:12 시점 기록처럼 재시작했으며 실제 30설정 결과 보고서는 아직 미완료다. 독립 재검증 뒤 실행에서 실제 완료한 fold만 집계한다. 의료 원본·개별 환자/영상 키·특징·가중치·OOF 확률·운영 로그는 공개하지 않는다.
