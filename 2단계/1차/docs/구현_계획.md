# 2단계 실제 CT 전이 구현 계획

> 구현 계획과 학습 전 준비 시점의 기록이다. 실제 완료된 분류 성능 보고서와 구분한다.

**목표:** 환자별 LUNA25 이진 분석과 IQ 3분류 탐색을 혼합 없이 재개 가능한 실제 학습 파이프라인으로 구성한다.

**구조:** `src/ct_transfer`에 데이터 경계·분할·모델·학습·평가·실행을 나눈다. 원본은 상위 1단계에서 읽으며 결과는 2단계 data/models/work에 둔다.

**기술:** 기존 Python 3.12, PyTorch/CUDA, NumPy, SciPy, scikit-learn, Pillow, 표준 ZIP64/LZMA를 사용한다. SimpleITK와 압축 유틸리티 설치는 필요하지 않다.

**명세:** [요구사항](요구사항.md)

## 전역 제약

1단계 동결 파일·원본 D드라이브 자료를 수정하지 않는다. IQ 환자 추정·라벨 혼합·외부 시험 라벨을 사용한 전역 의료 적응을 금지한다. 장기 학습은 독립 검증 뒤 시작한다. 운영 설정은 공개 범위에서 제외한다.

## 주요 검토 대상

- 객체 NPY에 들어 있는 임의 전역 함수·과도한 배열 할당.
- 분할 archive의 누락·해시 불일치·경로 이탈 및 동일 주석의 누락.
- 환자·정확 중복이 분할 사이에 겹치거나 클래스가 빠지는 경우.
- 재개 체크포인트에 다른 분할·설정·가중치를 사용하는 경우.
- 미완료 fold·합성 스모크를 실제 임상 결과 보고서로 생성하는 경우.

## 작업 1: 데이터·분할 경계

생성: `src/ct_transfer/io.py`, `data.py`, `splits.py`, `tests/test_contracts.py`.

- [x] 제한 메타데이터 파서·분할 ZIP 읽기·정확 중복·그룹 분할 실패 테스트를 먼저 실행한다.
- [x] `decode_metadata(raw)`, `ConcatReader(paths)`, `prepare_luna(...)`, `prepare_iq(...)`, `make_folds(records, ...)`를 구현한다.
- [x] 2단계의 단위 검사 명령으로 성공과 실패 경로를 검증한다.

## 작업 2: 모델·학습·평가

생성: `models.py`, `training.py`, `evaluation.py`, `tests/test_training.py`.

- [x] 악성 전역 함수·시험 fold 오염·재개 기준 불일치·작은 실제 head 학습 재개·미완료 보고 차단을 먼저 시험한다.
- [x] 1단계의 검토한 적재 코드를 별도 모듈명으로 읽고 가중치·소스 해시 검증을 유지한다.
- [x] `fit_model(...)`은 마지막/최적 체크포인트·RNG·optimizer를 원자 저장하고, 검증 분할로만 온도를 맞춘다.
- [x] 실제 검사 명령을 다시 실행한다. 자체 검사 결과를 독립 영수증으로 발급하지 않는다.

## 작업 3: 실행·자원 예산·후속 인계

생성: `pipeline.py`, `tools/run_stage2.py`, `configs/experiments.json`, `README.md`.

- [x] `prepare`/`benchmark`/`run` 명령을 구성한다. `benchmark`가 스모크를 수행하고 같은 `run`이 체크포인트로 재개한다. 완료 fold 재사용은 출처 결합 해시가 같은 경우에만 허용한다.
- [x] 실제 CT 소량의 CUDA 추론·학습 단계 시간을 측정한다. 이는 스모크이며 임상 성능이 아니다.
- [x] 측정에 근거한 30설정×7fold 및 별도 LUNA25 분석 실행 계획을 비공개 보존한다.
- [x] 소스를 동결하고 독립 검증한 뒤 장기 학습과 공개 반영을 진행한다.

실행 방식은 고정된 소스·자료·분할·예산의 결합을 따른다. 공개 반영에는 별도 독립 검토를 적용한다.

첫 실행 전 33검사 통과와 실제 첫 실행의 단일 원소 배치 실패 기록은 보존했다. 수리 뒤 36검사를 통과했고 현재 소스로 공통 배치 16의 자원 측정·실행 예산을 다시 고정했다. 장기 학습과 공개 반영은 독립 재검증 뒤 진행한다. [실측 준비·검사 기록](구현_검증_기록.md)을 따른다.
