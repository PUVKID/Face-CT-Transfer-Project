# 2단계 요구사항과 분석 한계

확인일: 2026-11-03. 구현 단계의 사전 계약이며 실제 임상 결과가 아니다.

## 분석 A

LUNA25의 원래 얼굴 사전학습 고정 특징을 사용해 양성·악성 이진 분석을 수행한다. 환자 키는 `PatientID`이며 모든 결절·검사 시점은 같은 외부 fold에 둔다. 7개 외부 fold와 각 외부 학습 자료 안의 내부 검증을 고정한다. 전체 LUNA25로 적응한 모델은 이 분석에 금지한다.

## 분석 B

전체 LUNA25를 IQ와 분리된 보조 학습 자료로 사용해 의료 적응 체크포인트 하나를 만든다. 보조 적응 epoch는 사전 자원 예산으로 고정하며 이 자료에서의 독립 시험 성능을 만들지 않는다. 원래 얼굴/의료 적응 두 초기화와 동결/마지막 잔차 블록/전체 세 학습 범위를 다섯 시드로 비교해 30개 설정을 만든다. 동일 IQ 7-fold와 내부 검증·학습 예산을 공유한다. 이는 6개 방법의 5회 반복이며 30개 독립 방법이 아니다.

IQ의 정상·양성·악성 라벨만 사용한다. 파일명으로 환자를 추정하지 않고 디코딩된 동일 화소의 해시로 정확 중복을 묶는다. 클래스가 충돌하는 중복은 차단한다. 환자 키가 없으므로 환자 독립 성능·환자 신뢰구간·임상 일반화를 주장하지 않는다. LUNA25 결절 ROI와 IQ 정상 영상을 한 클래스 테이블로 합치지 않는다.

보유 1,097개 영상은 [저자 GitHub의 고정 commit](https://github.com/hamdalla93/The-IQ-OTHNCCD-lung-cancer-dataset/tree/edcdd5a73e8e92377d2a47e69c0b9a551e1c5ce3) JPG 1,097개와 상대 경로·바이트 길이·Git blob SHA-1이 모두 일치함을 확인했다. 비교 누락·추가·불일치는 0이다. 이 확인은 해당 GitHub 배포에 한정하며 Mendeley ZIP 전체와 환자 매핑은 검증하지 않았다. 설명의 1,190영상·110명을 현재 보유자료의 확정 수치로 적용하지 않는다.

## 공통 경계

- 원본은 1단계 data와 D드라이브 IQ 폴더를 읽기만 한다. 단계 2에는 파생 캐시만 생성한다.
- 모든 공식 분할 ZIP 조각의 고정 MD5와 크기를 확인한 뒤 읽는다. 객체 메타데이터는 임의 클래스를 실행하지 않는 제한 파서로 해석한다.
- 모델 입력은 RGB 3×112×112, [-1,1]이다. LUNA25는 50mm 시야·중앙 축상면·HU [-1000,400]을 사용한다. 이는 제작자 64픽셀 기준에서 112픽셀로 변경한 전처리다.
- 외부 시험 자료는 조기 종료·클래스 가중치·온도 보정·모델 선택에 사용하지 않는다. 모든 fold의 비어 있음·그룹 겹침·클래스 누락을 실제 검사한다.
- 원본 모델은 strict=True와 weights_only=True로 적재한다. BatchNorm 통계는 작은 IQ 배치에서 모든 학습 범위에 공통으로 고정한다. NCHW를 유지한다.
- AdamW, 학습률 warmup/cosine, 검증 macro-F1 조기 종료와 최적 모델 복원, 검증 전용 온도 보정을 사용한다. 클래스 가중치는 학습 분할에서만 계산한다.
- 실제 자원 벤치마크 뒤 배치 크기·epoch·인내 횟수·AMP·전체 실행 시간 상한을 기계 판독 예산으로 고정한다. CUDA 작업을 임의 종료하지 않는다.
- 장기 작업은 원자적 체크포인트·누적 JSONL·상태 파일로 재개한다. 재개 시 소스·자료·분할·설정의 불일치를 차단한다.
- OOF 확률·분할·전처리·온도·fold별 모델을 3단계에서 읽을 수 있도록 비공개 저장한다. 3단계용 모델 선택은 각 외부 fold의 내부 검증 점수만 사용한다.
- 정확도·균형 정확도·macro/weighted F1·클래스별 precision/recall·ROC-AUC·혼동행렬·Brier/NLL/ECE를 보고한다. 계산할 수 없는 지표를 0이나 1로 채우지 않는다.
- LUNA25에는 환자 단위 부트스트랩을 사용하고 IQ에는 환자 신뢰구간을 만들지 않는다. 시드 반복과 7개 fold를 독립 환자 표본으로 간주하지 않는다.
- 개별 환자·특징·원영상·가중치·비공개 로그는 공개하지 않는다. 30개 Markdown 결과는 각 설정의 7개 fold가 실제 완료된 뒤 집계 결과만 생성한다.
